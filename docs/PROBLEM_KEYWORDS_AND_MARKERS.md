# 🎯 Словник Слів-Маркерів та Логічних Тригерів Олімпіадних Задач (Problem Signal Keywords & Logical Triggers)

> **Золоте правило олімпіадника:** Журі рідко вигадує принципово нові структури даних з нуля — вони ховають класичні патерни за специфічними формулюваннями умови. Якщо ви знаєте **слова-маркери** та **сигнатури обмежень**, ви визначаєте алгоритм за перші 60 секунд читання задачі!

## 🧭 Швидка Таблиця Миттєвих Тригерів (Cheat Sheet)

| Слова-маркери в умові | Сигнатура обмежень | Справжній алгоритмічний патерн | Типова пастка / False Friend |
|---|---|---|---|
| *"Мінімізувати максимум"*, *"максимізувати мінімальну відстань"*, *"чи можливо досягти X"* | $N \le 2 \cdot 10^5$, перевірка $O(N)$ | **Бінарний пошук по відповіді** | Жадібний вибір без бінарного пошуку дає WA |
| *"Неперервний підмасив"*, *"знайти відрізок довжини $\ge K$ з сумою $\ge S$"*, всі $A_i \ge 0$ | $N \le 10^6, O(N)$ | **Два вказівники / Ковзне вікно** | Якщо є від'ємні числа, монотонність руйнується! |
| *"Кількість підмасивів із сумою $K$"*, числа можуть бути від'ємними | $N \le 2 \cdot 10^5, A_i \in [-10^9, 10^9]$ | **Префіксні суми + Хеш-таблиця** (`pref[R] - pref[L] = K`) | Спроба застосувати два вказівники на від'ємних числах |
| *"Найближчий більший/менший елемент ліворуч/праворуч"*, *"прямокутник у гістограмі"* | $N \le 10^6, O(N)$ | **Монотонний стек (Monotonic Stack)** | Квадратичний вкладений цикл $O(N^2)$ (TLE) |
| *"Оновлення в точці, запит суми/мінімуму на відрізку"* | $N, Q \le 2 \cdot 10^5, O(\log N)$ | **Дерево відрізків / Дерево Фенвіка** | Префіксні суми без динамічних оновлень |
| *"Додати $V$ до всіх елементів на $[L, R]$, дізнатися значення в кінці"* | $N, Q \le 10^6, O(1)$ оновлення | **Різницевий масив (Difference Array)** `d[L] += V, d[R+1] -= V` | Дерево відрізків — зайвий оверхед за часом і пам'яттю |
| *"Масове додавання на $[L, R]$ ТА запити суми/мінімуму в перемішку"* | $N, Q \le 2 \cdot 10^5$ | **Дерево відрізків з Lazy Propagation** | Звичайне ДО без лінивих оновлень дає $O(N)$ на запит |
| *"Розподілити предмети між двома або трьома"*, *"порядок обходу всіх міст"*, $N \le 20$ | $N \le 20, 2^N \approx 10^6, 3^N \approx 3.5 \cdot 10^9$ | **ДП по бітових масках (Bitmask DP)** | Повний перебір $N!$ (TLE) |
| *"Розбити множину на дві рівні підмножини"*, $N \le 40$ | $N \le 40, 2^{N/2} = 2^{20} \approx 10^6$ | **Meet-in-the-middle (Зустріч посередині)** | $2^{40} \approx 10^{12}$ падає по TLE; DP не влізе, якщо ваги $10^{12}$ |
| *"Рюкзак, але вага предмета $W_i \le 10^9$, а вартість $V_i \le 100$"* | $\sum V_i \le 10^4$ | **ДП, де стан — мінімальна вага для вартості $V$** `dp[v] = min_w` | Стандартне `dp[w]`, де $W \le 10^9$ дає MLE |
| *"Оптимальний вибір у дереві: вибрати незалежну множину вершин"*, зв'язний ациклічний граф | $N \le 2 \cdot 10^5$ | **Tree DP (ДП на дереві, DFS знизу-вгору)** | Спроба застосувати топологічне сортування без дерева |
| *"Шляхи між парою вершин у дереві, багато запитів"* | $N, Q \le 2 \cdot 10^5$ | **LCA через Binary Lifting (Двійкові підйоми)** | Запуск BFS для кожного запиту окремо ($O(Q \cdot N) \to$ TLE) |
| *"Ваги ребер графа дорівнюють лише 0 або 1"* | $V, E \le 5 \cdot 10^5$ | **0-1 BFS на двобічній черзі (`std::deque`)** | Дейкстра з купою дає зайвий $\log V$ і може не влізти в жорсткий TL |
| *"Зв'язати всі вершини з мінімальною сумарною вагою"*, *"динамічно перевіряти зв'язність"* | $V, E \le 2 \cdot 10^5$ | **DSU (Система неперетинних множин) / Kruskal** | Дейкстра або пошук шляху замість кістяка |
| *"Розбити об'єкти на 2 групи так, щоб не було конфліктів у парах"* | $N \le 2 \cdot 10^5$ | **Двочастковий граф (Перевірка на 2-розфарбовуваність через BFS/DFS)** | Жорсткий NP-hard перебір замість перевірки на непарні цикли |
| *"Кожна умова має вигляд: або $A$, або $B$ має бути істинним"* | $N \le 10^5$ | **2-SAT (Сильно зв'язні компоненти Косараджу / Тар'яна)** | Експоненційний пошук або жадібні евристики |
| *"Знайти кількість шляхів довжини $K$ у графі"*, $K \le 10^{18}, N \le 100$ | $N \le 100, K \le 10^{18}$ | **Матричне швидке піднесення до степеня** $O(N^3 \log K)$ | Спроба звичайного ДП довжиною $K$ (TLE) |
| *"Гра двох гравців, кожен грає оптимально, фінальний стан визначений"* | Стан скінченний | **Теорія ігор: Sprague-Grundy, Нім-сума (XOR)** | Спроба жадібного ходу на 1 крок вперед |
| *"Знайти $K$-те входження підрядка"*, *"циклічні зсуви рядка"* | $|S| \le 10^6$ | **Поліноміальне хешування / KMP / Z-функція** | Квадратичне порівняння $O(|S| \cdot |P|)$ через `std::string::find` |
| *"Інтерактивна задача: вгадати число/граф за $\le 30$ запитів"* | Запитів $\le \lceil \log_2 N \rceil$ | **Бінарний пошук / Зважений ternary search** | Забутий `fflush(stdout)` або `std::endl` $\to$ Idle Limit Exceeded |

## 🔍 Детальний Розбір Сигналів за Категоріями

### 1. Пошук, Оптимізація та Екстремуми

#### 🔑 Маркер 1.1: "Мінімізувати максимум" або "Максимізувати мінімум"
- **Типові фрази в умові:**
  - *"Розбийте масив на $K$ частин так, щоб максимальна сума частини була якомога меншою."*
  - *"Розставте корів у стійлах так, щоб мінімальна відстань між ними була максимальною."*
  - *"Знайдіть найменшу швидкість, за якої кур'єр встигне виконати замовлення до дедлайну."*
- **Алгоритмічний вердикт:** **Бінарний пошук по відповіді (Binary Search on Answer)**.
- **Чому це працює:** Якщо швидкість $V$ дозволяє встигнути, то будь-яка швидкість $> V$ також підходить (монотонність функції `can(V)`).
- **Шаблон мислення:**
  ```cpp
  long long L = min_ans, R = max_ans, best = R;
  while (L <= R) {
      long long mid = L + (R - L) / 2;
      if (check(mid)) {
          best = mid;
          R = mid - 1; // для мінімізації
      } else {
          L = mid + 1;
      }
  }
  ```

#### 🔑 Маркер 1.2: "Знайти екстремум функції з одним піком" (Унімодальна функція)
- **Типові фрази в умові:**
  - *"Знайти точку на осі, сума відстаней від якої до заданих точок мінімальна."*
  - *"Функція спочатку спадає, а потім строго зростає, знайти точку мінімуму з точністю $10^{-7}$."*
- **Алгоритмічний вердикт:** **Тернарний пошук (Ternary Search)**.

### 2. Відрізки, Підмасиви та Послідовності

#### 🔑 Маркер 2.1: "Неперервний підмасив з монотонною властивістю"
- **Типові фрази в умові:**
  - *"Знайдіть найдовший підмасив, у якому не більше ніж $K$ різних чисел."*
  - *"Знайдіть найкоротший підвідрізок із сумою не менше за $S$ (всі елементи строго додатні)."*
- **Алгоритмічний вердикт:** **Два вказівники (Two Pointers) / Ковзне вікно (Sliding Window)** за $O(N)$.
- **Критична перевірка:** Якщо елементи можуть бути від'ємними — два вказівники ламаються! Переходьте до **префіксних сум з `std::unordered_map`** або дерева відрізків.

#### 🔑 Маркер 2.2: "Найближчий більший/менший елемент" або "Площа прямокутників"
- **Типові фрази в умові:**
  - *"Для кожного дня знайдіть перший наступний день із вищою температурою."*
  - *"Знайти найбільшу площу прямокутника під гістограмою."*
  - *"Для кожного елемента знайти найдовший підмасив, де він є мінімумом."*
- **Алгоритмічний вердикт:** **Монотонний стек (Monotonic Stack)** за $O(N)$.

### 3. Динамічне Програмування (DP Signals)

#### 🔑 Маркер 3.1: "Мале $N \le 20$, оптимізація перестановки/підмножин"
- **Типові фрази в умові:**
  - *"Знайти найкоротший замкнений маршрут, що відвідує кожне місто рівно один раз."*
  - *"Розбити $N$ завдань між двома працівниками так, щоб мінімізувати час."*
  - *"Згрупувати $2N$ людей у $N$ пар з мінімальною сумарною невідповідністю."*
- **Алгоритмічний вердикт:** **Bitmask DP ($O(2^N \cdot N)$ або $O(3^N)$)**.
- **Підказка:** Якщо $N \le 40$ — це НЕ Bitmask DP, а **Meet-in-the-middle** ($2^{20} + 2^{20} \approx 2 \cdot 10^6$ операцій).

#### 🔑 Маркер 3.2: "Кількість чисел на проміжку $[L, R]$, які задовольняють умову"
- **Типові фрази в умові:**
  - *"Скільки чисел між $A$ та $B$ не містять двох однакових цифр поспіль?"*
  - *"Скільки чисел мають суму цифр, що ділиться на $K$?"* ($B \le 10^{18}$)
- **Алгоритмічний вердикт:** **Digit DP (ДП по цифрах)**: стан `dp[idx][is_less][is_started][extra_state]`.
- **Логічний прийом:** Відповідь на інтервалі $[L, R]$ обчислюється як $solve(R) - solve(L - 1)$.

#### 🔑 Маркер 3.3: "Залежність між сусідніми елементами в дереві"
- **Типові фрази в умові:**
  - *"Вибрати максимальну за вагою підмножину вершин дерева, жодні дві з яких не з'єднані ребром."*
  - *"Для кожної вершини дерева знайти суму відстаней до всіх інших вершин."*
- **Алгоритмічний вердикт:** **Tree DP** (1 або 2 проходи DFS: знизу-вгору, перепідвішування кореня rerooting).

### 4. Теорія Графів та Зв'язність

#### 🔑 Маркер 4.1: "Ребра з вагами 0 або 1"
- **Типові фрази в умові:**
  - *"Ви можете пройти по дорозі безкоштовно або розвернути стрілку світлофора за 1 монету."*
  - *"Знайдіть мінімальну кількість операцій інверсії, щоб зв'язати початок і кінець лабіринту."*
- **Алгоритмічний вердикт:** **0-1 BFS (`std::deque`)**. Ребро 0 додається через `push_front()`, ребро 1 через `push_back()`. Складність $O(V + E)$ без логарифма!

#### 🔑 Маркер 4.2: "Розбити на дві несумісні групи"
- **Типові фрази в умові:**
  - *"Чи можна розсадити учнів за 2 столи так, щоб вороги не сиділи разом?"*
  - *"Чи можна пофарбувати вершини графа у 2 кольори без однакових сусідів?"*
- **Алгоритмічний вердикт:** **Перевірка на двочастковість (Bipartite Graph Check via BFS/DFS)**. Якщо є цикл непарної довжини — відповідь `NO`.

#### 🔑 Маркер 4.3: "Вибір 'або те, або інше' для пар змінних"
- **Типові фрази в умові:**
  - *"Кожен гість бажає страву $X$ або не бажає $Y$, треба задовольнити всіх."*
  - *"Розставити знаки $+$ або $-$ так, щоб виконувалися системні обмеження пар."*
- **Алгоритмічний вердикт:** **2-SAT (2-Satisfiability)** через пошук компонент сильної зв'язності (SCC). Змінна $x$ та її заперечення $\neg x$ не повинні належати одній SCC.

### 5. Математика, Теорія Чисел та Біти

#### 🔑 Маркер 5.1: "Скільки підмножин мають максимальний XOR"
- **Типові фрази в умові:**
  - *"Виберіть підмножину елементів із максимально можливою побітовою сумою XOR."*
  - *"Чи можна утворити число $X$ як XOR підмножини заданих чисел?"*
- **Алгоритмічний вердикт:** **Базис Гаусса в $\mathbb{F}_2$ (Linear XOR Basis)** за $O(N \log (\max A))$.

#### 🔑 Маркер 5.2: "Обчислити $N$-й член послідовності при $N \le 10^{18}$"
- **Типові фрази в умові:**
  - *"Знайдіть $N$-те число Фібоначчі за модулем $10^9+7$ для $N = 10^{18}$."*
  - *"Кількість замощень смужки $2 \times N$ плитками для великого $N$."*
- **Алгоритмічний вердикт:** **Матричне швидке піднесення до степеня** $O(K^3 \log N)$, де $K$ — порядок рекуренти.

## ⚡ Олімпіадний Чек-лист: 6 Запитань за 60 Секунд

Коли відкриваєте нову умову, дайте швидкі відповіді на 6 контрольних пунктів:
1. **Яке $N$?**
   - $N \le 20 \implies$ Bitmask DP / перебір з відсіканнями.
   - $N \le 40 \implies$ Meet-in-the-middle ($2^{20} \approx 10^6$).
   - $N \le 2000 \implies O(N^2)$ ДП, граф, матриці.
   - $N \le 2 \cdot 10^5 \implies O(N \log N)$ (сортування, бінарний пошук, дерево відрізків).
   - $N \le 10^7 \implies O(N)$ (лінійне решето, префіксні суми, два вказівники).
   - $N \le 10^{18} \implies O(\log N)$ (матриці, двійкове піднесення, теорія чисел).
2. **Чи є монотонність?** (Якщо "так" для $X$, то автоматично "так" для всіх $Y > X$?) $\implies$ **Бінарний пошук по відповіді**.
3. **Чи можна розбити масив на дві половини незалежно?** $\implies$ **Meet-in-the-middle / Divide & Conquer**.
4. **Чи зберігається історія змін або потрібні відкати?** $\implies$ **Персистентні структури даних / DSU з відкатами (rollback)**.
5. **Чи граф орієнтований та ациклічний (DAG)?** $\implies$ **Топологічне сортування + ДП на вершинах**.
6. **Чи задача про гру двох гравців?** $\implies$ **Обчислити Нім-суму (XOR) або Grundy-функцію**.
