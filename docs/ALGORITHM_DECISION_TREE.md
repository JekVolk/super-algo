# 🌳 Дерево Прийняття Рішень: Який Алгоритм Обрати? (Algorithm Decision Tree)

Цей посібник слугує навігатором для олімпіадника: дивлячись на тип запитання та формулювання умови, ви миттєво обираєте точний алгоритм із бази знань (від легких до світового рівня).

## 🗂️ Детальна класифікація за типами задач

### 1. Задачі типу "Підрахунок на відрізках" (Range Queries)
- **Рівень 1 (Легкий):** Префіксні суми, двовимірні префіксні суми, різницевий масив.
- **Рівень 2 (Середній):** Дерево Фенвіка (Binary Indexed Tree), Дерево відрізків (точкове оновлення).
- **Рівень 3 (Олімпіадний):** Дерево відрізків з відкладеними операціями (Lazy Propagation).
- **Рівень 4 (Топ-рівень):** Персистентне дерево відрізків, Segment Tree Beats, Merge-Sort Tree, Treap по неявному ключу.

### 2. Задачі типу "Знайди оптимум" (Optimization & Extremum)
- **Якщо функція вибору очевидна:** Жадібний вибір + сортування за кастомним компаратором.
- **Якщо можна зафіксувати відповідь:** Бінарний пошук по відповіді (Bisection).
- **Якщо треба відновити послідовність виборів:** Динамічне програмування з масивом предків `p[state]`.
- **Якщо обмеження $N \le 40$:** Meet-in-the-middle (розділити на дві половини $2^{20}$, згенерувати і сперти через два вказівники/двійковий пошук).

### 3. Задачі на деревах (Tree Specifics)
- **Діаметр дерева:** 2 рази запустити BFS/DFS (перший знаходить найвіддаленішу вершину $u$, другий з $u$ дає діаметр).
- **LCA (Найменший спільний предок):** Binary Lifting `up[u][i]` за $O(N \log N)$ передпідрахунку та $O(\log N)$ на запит.
- **Піддерево як відрізок:** Ейлерів обхід дерева ($tin[u] \dots tout[u]$ перетворює запити на піддереві у звичайний відрізок у дереві відрізків).
