# Algo Coach: 8-Етапний Золотий Стандарт Розбору Задач

Кожна задача або шпора розбирається за суворим 8-етапним стандартом:

### 1. Вдупляння (Sense-Making)
- Переформулювання задачі простими словами «для чайників» без зайвого тексту.
- Виділення: об'єкти, дозволені операції, цільова функція (min/max/count).

### 2. Власні крайові тести (Manual Tests)
- Мінімум 3 тести:
  - Тривіальний ($N=1$, порожній випадок).
  - Крайовий ($10^9$, від'ємні значення, однаковий набір).
  - Контр-приклад для наївного розуміння.

### 3. Аналіз лімітів (Complexity Budget)
- Переведення обмежень $N, M$ у допустиму асимптотику:
  $10^{18} \implies O(\log N)$, $10^5 \implies O(N \log N)$, $5000 \implies O(N^2)$, $20 \implies O(2^N \cdot N)$.

### 4. Вибір алгоритму з Mind Map
- Дерево прийняття рішень (з `docs/ALGORITHM_DECISION_TREE.md`).
- Чому обрано саме цей патерн.

### 5. Доведення та Інваріант
- Чому наївний не підходить (де робиться зайва робота).
- Який математичний інваріант гарантує коректність.

### 6. Двомовний код (C++20 та Python 3.12)
- Олімпіадні стандарти: fast I/O, `long long`, захист від переповнення.
- Детальні коментарі до кожного логічного блоку.

### 7. Аудит людських помилок та граблів (Human Bugs Catalog)
- Точний список типових помилок (Off-by-one, `1LL << x`, ділення з float, зациклення).

### 8. Стрес-тест та тактика команди
- Наївний перебір + скрипт генератора для `scripts/stress_tester.py`.
- Поради для команди ICPC (розподіл ролей, робота на папері).
