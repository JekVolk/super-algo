# Algo Pedagogy & Visualizer: Глибока Деталізація та Автоматизація

## 🔬 Ланцюжок Педагогічної Деталізації (5 Рівнів Глибини)
Кожне пояснення задачі розгортає повну цепочку роздумів:

1. **Рівень 1: Візуалізація проблеми в голові (Mental Model)**
   - Про що насправді ця задача, якщо забути про формули?
   - Метафора процесу (наприклад, для задачі про антивірус — пожежна хвиля, що гасне поверхами).
2. **Рівень 2: Руйнування наївного міркування (Dead-End Exploration)**
   - Як би цю задачу розв'язав початківець «в лоб»?
   - Чому цей шлях веде в глухий кут ($O(N \cdot K)$ або експонента).
3. **Рівень 3: Народження Інсайту (Aha! Moment)**
   - Яка прихована симетрія, монотонність або топологічний порядок закладені в умову?
   - Чому саме цей інваріант знімає зайві обчислення.
4. **Рівень 4: Математичне Доведення у LaTeX**
   - Точні формули для переходів динаміки / дерев / графів.
   - Захист від OCR-артефактів.
5. **Рівень 5: Інженерна реалізація та захист від олімпіадних багів**
   - Вибір типів даних (`long long` vs `int`, `double` vs цілочисельна арифметика).
   - Fast I/O, `endl` vs `\n`.

## 🛠️ Автоматизація Вилучення Задач з Eolymp
Система підтримує 3 автоматичні канали для затягування задач з Eolymp Space:
1. **Competitive Companion:** локальний слухач на порті 10043 (`scripts/companion_listener.py`). Одне натискання зеленого плюсика в браузері — і задача разом з лімітами та тестами створюється у потрібній папці!
2. **Eolymp Scraper (`scripts/eolymp_scraper.py`):**
   - Підтримка зчитування Next.js RSC payload (`self.__next_f.push`).
   - Парсинг base64-закодованих зразків тестів.
   - Робота через сесійну куку (`--cookie "eolymp_session=..."`) для закритих контестів UCPC.
3. **HTML / DevTools Direct Extractor:**
   - Можливість вставки зліпка HTML-сторінки напряму з консолі розробника для миттєвої генерації структури.
