# Задача 2: Паритет паліндрому (Can Form Palindrome)

## 1. Вдупляння (Sense-Making)
Дано рядок $S$, що складається з малих літер латинського алфавіту. Чи можливо так переставити символи цього рядка, щоб утворився паліндром (рядок, який однаково читається зліва направо і справа наліво)?
Вивести `YES`, якщо це можливо, або `NO`, якщо ні.

## 2. Ручні крайові тести
1. **Тест 1 (Один символ):** $S = \text{"a"}$. Очевидно паліндром $\implies$ `YES`.
2. **Тест 2 (Парні частоти):** $S = \text{"aabb"}$. Можна утворити $\text{"abba"}$ $\implies$ `YES`.
3. **Тест 3 (Більше однієї непарної частоти):** $S = \text{"abc"}$. Три непарні частоти $\implies$ `NO`.

## 3. Аналіз лімітів і бюджет часу
- $|S| \le 10^5$.
- Час: 1.0 сек (до $10^8$ операцій).
- Необхідна складність: $O(|S|)$ часу, $O(\Sigma) = O(26)$ додаткової пам'яті.

## 4. Вибір алгоритму з Mind Map
- [ALGORITHM_DECISION_TREE.md](../../docs/ALGORITHM_DECISION_TREE.md) -> 5. Рядки -> Частотний масив та бітова маска непарностей.

## 5. Доведення та Інваріант
Рядок можна переставити у паліндром тоді і тільки тоді, коли кількість символів з **непарною частотою появи не перевищує 1**:
- Якщо довжина рядка парна, всі символи зобов'язані мати парну кратність.
- Якщо довжина рядка непарна, рівно один символ стоїть у центрі паліндрома (має непарну кратність), а всі інші розподіляються симетрично по краях.
Інваріант: `odd_count <= 1`.

## 6. Двомовний код

### Python 3.12
```python
import sys
from collections import Counter

def solve():
    s = sys.stdin.readline().strip()
    if not s:
        return
    counts = Counter(s)
    odd = sum(1 for c in counts.values() if c % 2 != 0)
    print("YES" if odd <= 1 else "NO")

if __name__ == "__main__":
    solve()
```

### C++20
```cpp
#include <iostream>
#include <string>
#include <vector>

using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    string s;
    if (!(cin >> s)) return 0;

    int mask = 0; // бітова маска непарностей для 26 літер
    for (char c : s) {
        mask ^= (1 << (c - 'a'));
    }

    // Якщо кількість одиничних бітів <= 1
    if ((mask & (mask - 1)) == 0) {
        cout << "YES\n";
    } else {
        cout << "NO\n";
    }
    return 0;
}
```

## 7. Аудит граблів та людських помилок
1. **Перебір перестановок через `std::next_permutation`:** складність $O(|S|!)$ гарантує миттєвий `TLE` при $|S| > 10$.
2. **Зайві пробіли/переноси рядків:** зчитування рядка з `\r` на Windows призводить до хибного врахування спецсимволу `\r`. Потрібно робити `.strip()`.

## 8. Стрес-тест та командна стратегія
- **Бітовий трюк:** `(mask & (mask - 1)) == 0` перевіряє, що у масці не більше одного встановленого біта за $O(1)$.
- **ICPC Тактика:** Пишеться другим учасником за 1 хвилину, не блокуючи комп'ютер для складних задач.
