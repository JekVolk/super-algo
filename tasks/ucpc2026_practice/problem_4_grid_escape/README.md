## 1. Вдупляння (Sense-Making)

### 🔥 ELI5 — Аналогія для 10-річного

Уяви **аркуш паперу в клітинку** — це твій лабіринт. Деякі клітинки зафарбовані чорним (`#` — стіна), деякі порожні (`.`).

Тепер **підпали** клітинку `S`. Вогонь рівномірно розповзається кожну секунду на всі 4 сусідні клітинки, **якщо вони не заблоковані стіною**. Через скільки секунд вогонь торкнеться клітинки `E`?

> Ось це й є **BFS** — вогонь завжди спочатку заповнює найближчі клітинки, і тільки потім іде далі. Тому перший раз, коли він дістане `E`, — це і є **найкоротший шлях**.

---

### 🎯 Чітке формулювання

| Об'єкти | Операції | Ціль |
|---|---|---|
| Сітка $N \times M$ з клітинками `S`, `E`, `.`, `#` | Перехід між 4 сусідніми клітинками за 1 крок | Знайти **мінімальну кількість кроків** від `S` до `E`, або `-1` якщо шляху немає |

**Символи:**
- `'S'` — точка старту (Start);
- `'E'` — вихід (Exit);
- `'.'` — вільний коридор;
- `'#'` — непрохідна кам'яна стіна.

## 2. Ручні крайові тести

### Тест 1 — Прямий коридор
```text
Вхід:
1 3
S.E
```
**Покрокове міркування:**
- Крок 0: знаходимось у `(0,0)` = `S`.
- Крок 1: переходимо вправо → `(0,1)` = `.`.
- Крок 2: переходимо вправо → `(0,2)` = `E`. ✅

**Відповідь:** `2`

---

### Тест 2 — Повний глухий кут
```text
Вхід:
2 2
S#
#E
```
**Покрокове міркування:**
- З `(0,0)` = `S` можна піти лише вниз → `(1,0)` = `#` (стіна), або вправо → `(0,1)` = `#` (стіна).
- Жодного вільного сусіда немає — черга порожніє, `E` не досягнуто.

**Відповідь:** `-1`

---

### Тест 3 — Звивистий шлях-змійка
```text
Вхід:
3 3
S.#
#.#
#.E
```
**Покрокове міркування:**
- Крок 0: `(0,0)` = `S`.
- Крок 1: вправо → `(0,1)`.
- Крок 2: вниз → `(1,1)`.
- Крок 3: вниз → `(2,1)`.
- Крок 4: вправо → `(2,2)` = `E`. ✅

**Шлях:** $(0,0) \to (0,1) \to (1,1) \to (2,1) \to (2,2)$

**Відповідь:** `4`

### Тест 4 — Старт одразу на фініші
```text
Вхід:
1 1
S
```
*Якщо `E` відсутнє — неможливо дійти.*

**Відповідь:** `-1`

## 3. Аналіз лімітів і бюджет часу

- Розміри сітки: $1 \le N, M \le 1000$. Загальна кількість клітинок $V = N \times M \le 10^6$.
- Кількість переходів (ребер): не більше 4 ребер з кожної клітинки, отже $E \le 4 \cdot 10^6$.
- Ліміт часу: **1.0 сек** (дозволяє до $\approx 10^8$ операцій).
- Ліміт пам'яті: **256 MB**.

**Оцінка складності:**
| Характеристика | Значення |
|---|---|
| Часова складність | $O(N \cdot M)$ — кожна клітинка відвідується рівно раз |
| Пам'ять | $O(N \cdot M)$ — масив `dist` розміром $1000 \times 1000 \times 4$ байти $\approx 4$ МБ |

## 5. Доведення та Інваріант

### 🔥 Чому наївний підхід (DFS) ламається?

**DFS знаходить довільний шлях, а не найкоротший.** Щоб знайти найкоротший через DFS, треба перебирати всі можливі траєкторії:
- Кількість траєкторій у найгіршому випадку: $O(4^{N \cdot M})$ — катастрофічний **TLE** вже при $N = M = 15$.
- Глибина рекурсії при $N \cdot M = 10^6$: Python падає від `RecursionError`, C++ — від `SIGSEGV` (переповнення стеку).

**Де DFS «задихається»:** він може зробити 999 000 кроків у хибному напрямку, перш ніж повернутися і знайти правильний шлях довжиною 10.

---

### 📐 Математичний інваріант BFS

Черга `queue` у будь-який момент часу підтримує **монотонність відстаней**:
$$\text{dist}[v_1] \le \text{dist}[v_2] \le \dots \le \text{dist}[v_k]$$

Різниця між першим та останнім елементом у черзі ніколи не перевищує 1:
$$\text{dist}[\text{tail}] - \text{dist}[\text{head}] \le 1$$

Коли ми **вперше** дістаємо вершину `E` з черги — знайдена відстань **гарантовано є мінімальною**.

---

### 📋 Псевдокод BFS (5 кроків)

```
1. Знайти позицію S (старт) і E (фініш) у сітці.
2. Створити масив dist[N][M] = -1 (усі невідвідані).
   Встановити dist[S] = 0. Покласти S у чергу.
3. Поки черга не порожня:
   а) Взяти клітинку (r, c) з ПОЧАТКУ черги (FIFO!).
   б) Якщо (r, c) == E — повернути dist[r][c]. СТОП.
   в) Для кожного з 4 напрямків (вгору/вниз/вліво/вправо):
      - Якщо сусід (nr, nc) в межах поля, не стіна, не відвіданий:
        · dist[nr][nc] = dist[r][c] + 1
        · Додати (nr, nc) у КІНЕЦЬ черги.
4. Якщо черга спорожніла, а E не досягнуто → повернути -1.
```

## 6. Двомовний код

### 🐍 Python 3.12 (Еталонне олімпіадне рішення)

```python
import sys
from collections import deque

def solve():
    # --- Зчитування вхідних даних одним блоком (швидше ніж input()) ---
    input_data = sys.stdin.read().split()
    if not input_data:
        return

    n = int(input_data[0])   # кількість рядків
    m = int(input_data[1])   # кількість стовпців
    grid = input_data[2:2 + n]  # рядки сітки

    # --- Пошук стартової та цільової клітинок ---
    start = None
    target = None
    for r in range(n):
        for c in range(m):
            if grid[r][c] == 'S':
                start = (r, c)
            elif grid[r][c] == 'E':
                target = (r, c)

    # --- Захист: якщо S або E відсутні ---
    if not start or not target:
        print(-1)
        return

    # --- Ініціалізація BFS ---
    dist = [[-1] * m for _ in range(n)]  # -1 = не відвідано
    q = deque([start])
    dist[start[0]][start[1]] = 0          # відстань до старту = 0

    # Вектори напрямків: вгору, вниз, вліво, вправо
    dr = [-1, 1,  0, 0]
    dc = [ 0, 0, -1, 1]

    # --- Основний цикл BFS ---
    while q:
        r, c = q.popleft()  # беремо з ПОЧАТКУ черги (FIFO — ключово!)

        # Досягли виходу — повертаємо відповідь
        if (r, c) == target:
            print(dist[r][c])
            return

        cur_d = dist[r][c]
        for i in range(4):
            nr, nc = r + dr[i], c + dc[i]

            # Перевірка меж, стін і відвіданості
            if 0 <= nr < n and 0 <= nc < m and grid[nr][nc] != '#':
                if dist[nr][nc] == -1:          # ще не відвідана
                    dist[nr][nc] = cur_d + 1    # ← позначаємо ТУТ (перед push!)
                    q.append((nr, nc))

    # --- E недосяжний ---
    print(-1)

if __name__ == "__main__":
    solve()
```

### ⚡ C++20 (Швидке олімпіадне рішення)

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <queue>

using namespace std;

// Структура для зберігання координати клітинки
struct Cell {
    int r, c;
};

// Вектори напрямків: вгору, вниз, вліво, вправо
const int dr[4] = {-1, 1,  0, 0};
const int dc[4] = { 0, 0, -1, 1};

int main() {
    // Прискорення введення/виведення
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    if (!(cin >> n >> m)) return 0;  // захист від порожнього вводу

    // --- Зчитування сітки та пошук S і E ---
    vector<string> grid(n);
    Cell start{-1, -1}, target{-1, -1};

    for (int r = 0; r < n; ++r) {
        cin >> grid[r];
        for (int c = 0; c < m; ++c) {
            if (grid[r][c] == 'S') start  = {r, c};
            if (grid[r][c] == 'E') target = {r, c};
        }
    }

    // --- Захист: якщо S або E відсутні ---
    if (start.r == -1 || target.r == -1) {
        cout << -1 << "\n";
        return 0;
    }

    // --- Ініціалізація BFS ---
    vector<vector<int>> dist(n, vector<int>(m, -1)); // -1 = не відвідано
    queue<Cell> q;

    dist[start.r][start.c] = 0;  // відстань до старту = 0
    q.push(start);

    // --- Основний цикл BFS ---
    while (!q.empty()) {
        auto [r, c] = q.front();  // беремо з ПОЧАТКУ черги (FIFO — ключово!)
        q.pop();

        // Досягли виходу — повертаємо відповідь
        if (r == target.r && c == target.c) {
            cout << dist[r][c] << "\n";
            return 0;
        }

        // Обходимо 4 сусіди
        for (int i = 0; i < 4; ++i) {
            int nr = r + dr[i];
            int nc = c + dc[i];

            // Перевірка меж, стін і відвіданості
            if (nr >= 0 && nr < n && nc >= 0 && nc < m && grid[nr][nc] != '#') {
                if (dist[nr][nc] == -1) {          // ще не відвідана
                    dist[nr][nc] = dist[r][c] + 1; // ← позначаємо ТУТ (перед push!)
                    q.push({nr, nc});
                }
            }
        }
    }

    // --- E недосяжний ---
    cout << -1 << "\n";
    return 0;
}
```

## 7. Аудит граблів та людських помилок

### ❌ Граблі 1 — DFS замість BFS

| | |
|---|---|
| ❌ **Помилка** | Використати `stack` (або рекурсію) замість `queue` |
| 💥 **Наслідок** | DFS знаходить якийсь шлях, але не найкоротший → **WA** на тестах зі звивистими лабіринтами; при глибині $10^6$ — **RE (RecursionError / SIGSEGV)** |
| ✅ **Правило** | Завжди використовуй `deque.popleft()` (Python) або `queue::front()` + `pop()` (C++) — строго FIFO! |

---

### ❌ Граблі 2 — Позначення відвіданих після `pop` замість `push`

| | |
|---|---|
| ❌ **Помилка** | Ставити `dist[nr][nc] = ...` лише при вилученні з черги, а не при додаванні |
| 💥 **Наслідок** | Одна клітинка додається в чергу до 4 разів від усіх сусідів. Черга розростається до $4 \cdot N \cdot M$ елементів → **MLE** або дуже повільний **TLE** |
| ✅ **Правило** | Позначай `dist[nr][nc] = cur_d + 1` **одразу перед** `q.append(...)` / `q.push(...)` |

---

### ❌ Граблі 3 — Переплутані N і M

| | |
|---|---|
| ❌ **Помилка** | Написати `if 0 <= nr < m and 0 <= nc < n` — переплутати рядки та стовпці |
| 💥 **Наслідок** | На квадратних тестах $N = M$ все проходить! Але на прямокутних ($10 \times 1000$) — гарантований **RE (IndexError / SIGSEGV)** або **WA** |
| ✅ **Правило** | Завжди: `nr` перевіряється проти `n` (рядки), `nc` — проти `m` (стовпці). Запам'ятай: **r**ow → **n**, **c**olumn → **m** |

---

### ❌ Граблі 4 — Забути вивести `-1` для неможливого шляху

| | |
|---|---|
| ❌ **Помилка** | Після порожньої черги просто завершити програму (не виводити нічого) |
| 💥 **Наслідок** | Порожній вивід не збігається з очікуваним `-1` → **WA** на всіх тестах із замурованим виходом |
| ✅ **Правило** | Після циклу BFS завжди дописуй `print(-1)` / `cout << -1` |

## 8. Стрес-тест та командна стратегія

### 🧪 Генератор лабіринтів для stress_tester.py

```python
# stress_tester.py — генератор випадкових лабіринтів для задачі 4
import random
import subprocess
import sys
from pathlib import Path

SOLUTION = Path(__file__).parent / "solution.py"

def generate_maze(n: int, m: int, wall_prob: float = 0.3) -> str:
    """
    Генерує випадковий лабіринт N×M.
    wall_prob — ймовірність, що клітинка є стіною '#'.
    S та E завжди розміщуються у кутах (не можуть бути стіною).
    """
    grid = []
    for r in range(n):
        row = []
        for c in range(m):
            # Кути завжди вільні (для S та E)
            if (r, c) in [(0, 0), (n-1, m-1)]:
                row.append('.')
            else:
                row.append('#' if random.random() < wall_prob else '.')
        grid.append("".join(row))

    # Розміщуємо S та E у протилежних кутах
    grid[0]   = 'S' + grid[0][1:]
    grid[n-1] = grid[n-1][:-1] + 'E'

    header = f"{n} {m}"
    return header + "\n" + "\n".join(grid)


def brute_force_bfs(input_str: str) -> int:
    """Еталонне BFS-рішення (довірений розв'язувач)."""
    from collections import deque
    lines = input_str.split()
    n, m = int(lines[0]), int(lines[1])
    grid = lines[2:2+n]

    start = target = None
    for r in range(n):
        for c in range(m):
            if grid[r][c] == 'S': start = (r, c)
            if grid[r][c] == 'E': target = (r, c)

    if not start or not target:
        return -1

    dist = [[-1]*m for _ in range(n)]
    q = deque([start])
    dist[start[0]][start[1]] = 0
    dr, dc = [-1,1,0,0], [0,0,-1,1]

    while q:
        r, c = q.popleft()
        if (r, c) == target:
            return dist[r][c]
        for i in range(4):
            nr, nc = r+dr[i], c+dc[i]
            if 0 <= nr < n and 0 <= nc < m and grid[nr][nc] != '#' and dist[nr][nc] == -1:
                dist[nr][nc] = dist[r][c] + 1
                q.append((nr, nc))
    return -1


def run_stress(iterations: int = 200):
    print(f"Запускаємо {iterations} стрес-тестів...")
    for i in range(iterations):
        n = random.randint(1, 15)
        m = random.randint(1, 15)
        wall_prob = random.uniform(0.1, 0.5)
        inp = generate_maze(n, m, wall_prob)

        expected = str(brute_force_bfs(inp))
        res = subprocess.run(
            [sys.executable, str(SOLUTION)],
            input=inp, text=True, capture_output=True
        )
        actual = res.stdout.strip()

        if actual != expected:
            print(f"❌ ЗНАЙДЕНО РОЗБІЖНІСТЬ на тесті #{i+1}!")
            print(f"Вхід:\n{inp}")
            print(f"Очікувалось: {expected}")
            print(f"Отримано:    {actual}")
            return

        if (i + 1) % 50 == 0:
            print(f"  ✓ {i+1}/{iterations} тестів пройдено...")

    print("✅ Усі стрес-тести пройшли!")


if __name__ == "__main__":
    run_stress(200)
```
