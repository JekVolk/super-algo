## ⚡ 8-Кроковий Золотий Стандарт Розбору

### 1. Вдупляння (Sense-Making)
Уявіть список із $n$ цілих чисел, записаних у довільному порядку. Необхідно переставити числа так, щоб кожне наступне число було не меншим за попереднє:
$$a_1 \le a_2 \le \dots \le a_n$$

**Що треба зробити:**
Зчитати кількість чисел $n$ та самі числа, відсортувати їх за неспаданням і вивести через один пробіл.

---

### 2. Ручні крайові тести
1. **$n = 1$:**  
   Вхід: `1 \n 42` $\implies$ Вихід: `42`. Масив з одного елемента вже відсортований.
2. **Усі числа однакові:**  
   Вхід: `4 \n 5 5 5 5` $\implies$ Вихід: `5 5 5 5`. Алгоритм повинен коректно обробляти дублікати (стабільність/непорушність).
3. **Зворотний порядок та від'ємні числа:**  
   Вхід: `5 \n 10 0 -5 -20 3` $\implies$ Вихід: `-20 -5 0 3 10`. Правильна обробка знаків.

---

### 3. Аналіз лімітів і бюджет часу
- $n \le 10^5$.
- Числа в діапазоні $[-10^9, 10^9]$.
- Ліміт часу: $1.0$ секунда ($\approx 10^8$ операцій).
- **Квадратичні сортування** ($O(n^2)$, як-от сортування бульбашкою Bubble Sort чи вибором Selection Sort) виконають $10^{10}$ операцій $\implies$ **Time Limit Exceeded (TLE)**!
- **Оптимальна складність:** $O(n \log n)$ — стандартний `std::sort` у C++ (Introsort: QuickSort + HeapSort + InsertionSort) або Timsort у Python.
- Пам'ять: $O(n)$ для зберігання масиву.

---

### 4. Вибір алгоритму з Mind Map
- [docs/ALGORITHM_DECISION_TREE.md](../../docs/ALGORITHM_DECISION_TREE.md) $\to$ **Arrays & Sorting** $\to$ **Comparison Sorting $O(n \log n)$**:
  - `std::sort` (C++20) або `list.sort()` (Python 3.12).
  - Для швидкого I/O обов'язково використовувати `ios_base::sync_with_stdio(false); cin.tie(nullptr);` у C++ та `sys.stdin.read().split()` у Python.

---

### 5. Доведення та Інваріант
Будь-який алгоритм сортування на основі порівнянь у гіршому випадку потребує не менше ніж $\Omega(n \log n)$ порівнянь за теоремою про інформаційне дерево розгалуження (оскільки існує $n!$ можливих перестановок, а висота бінарного дерева рішень $\lceil \log_2(n!) \rceil = \Theta(n \log n)$).

**Інваріант сортування:**
Після завершення сортування для всіх $0 \le i < n - 1$ виконується:
$$a[i] \le a[i+1]$$

### 6. Двомовний код (C++20 та Python 3.12)

#### C++20 (`solution.cpp`):
```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

int main() {
    // Прискорення потоків введення-виведення для олімпіадного контесту
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    if (cin >> n) {
        vector<long long> a(n);
        for (int i = 0; i < n; ++i) {
            cin >> a[i];
        }
        sort(a.begin(), a.end());
        for (int i = 0; i < n; ++i) {
            cout << a[i] << (i + 1 == n ? "" : " ");
        }
        cout << "\n";
    }
    return 0;
}
```

#### Python 3.12 (`solution.py`):
```python
import sys

def main():
    # Швидке зчитування всіх токенів з потоку stdin
    input_data = sys.stdin.read().split()
    if not input_data:
        return
    n = int(input_data[0])
    a = [int(x) for x in input_data[1:n+1]]
    a.sort()
    sys.stdout.write(" ".join(map(str, a)) + "\n")

if __name__ == "__main__":
    main()
```

### 7. Аудит граблів та людських помилок
1. **Повільне I/O у C++:** Використання `std::endl` замість `"\n"` скидає буфер на кожному з $10^5$ чисел $\implies$ гарантований TLE.
2. **Тип даних:** Числа до $10^9$ вміщуються в `int`, але для безпеки краще використовувати `long long` у C++.
3. **Форматування виводу:** Зайвий пробіл або перенос рядка рідко карається на сучасних тестувальних системах, але виведення `\n` наприкінці є обов'язковим стандартом ICPC.
