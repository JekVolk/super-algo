# Задача 1: Розминка A + B (Warmup A + B)

## 1. Вдупляння (Sense-Making)
У найпростішій задачі контесту перевіряється базове налаштування середовища (компілятор C++20, інтерпретатор Python 3.12), правильне підключення швидкого введення-виведення та коректна робота з великими 64-бітними цілими числами. Дано два цілих числа $A$ та $B$. Потрібно вивести їхню суму $A + B$.

## 2. Ручні крайові тести
1. **Тест 1 (Мінімальні / від'ємні значення):** $A = -10^{18}, B = -10^{18} \implies A + B = -2 \cdot 10^{18}$. Перевірка на знакові 64-бітні числа (`long long`).
2. **Тест 2 (Нулі):** $A = 0, B = 0 \implies A + B = 0$.
3. **Тест 3 (Великі додатні):** $A = 10^{18}, B = 10^{18} \implies 2 \cdot 10^{18} < 2^{63}-1$.

## 3. Аналіз лімітів і бюджет часу
- $-10^{18} \le A, B \le 10^{18}$.
- Час: 1.0 сек (допустимо до $10^8$ операцій).
- Необхідна складність: $O(1)$ часу, $O(1)$ пам'яті.

## 4. Вибір алгоритму з Mind Map
- [ALGORITHM_DECISION_TREE.md](../../docs/ALGORITHM_DECISION_TREE.md) -> 4. Числа та арифметика -> Пряме додавання.

## 5. Доведення та Інваріант
Сума двох 64-бітних цілих чисел у діапазоні $[-10^{18}, 10^{18}]$ лежить у межах $[-2 \cdot 10^{18}, 2 \cdot 10^{18}]$, що строго поміщається у знаковий тип `long long` у C++ (діапазон $[-9.22 \cdot 10^{18}, 9.22 \cdot 10^{18}]$) та автоматично підтримується довгою арифметикою Python.

## 6. Двомовний код

### Python 3.12
```python
import sys

def main():
    line = sys.stdin.read().split()
    if not line:
        return
    a = int(line[0])
    b = int(line[1])
    print(a + b)

if __name__ == "__main__":
    main()
```

### C++20
```cpp
#include <iostream>

using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    long long a, b;
    if (cin >> a >> b) {
        cout << a + b << "\n";
    }
    return 0;
}
```

## 7. Аудит граблів та людських помилок
1. **Використання 32-бітного `int`:** переповнення при сумі $> 2 \cdot 10^9$ дає від'ємний результат і `WA`.
2. **Повільний I/O:** відсутність `ios_base::sync_with_stdio(false)` при великій кількості запитів викликає `TLE`.
