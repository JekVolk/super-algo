## ⚡ 8-Кроковий Золотий Стандарт Розбору

### 1. Вдупляння (Sense-Making)
Уявіть файлову структуру з $n$ папок, пронумерованих від $1$ до $n$. Корінь — папка $1$. Усі інші папки $v \in [2, n]$ мають батьківську папку $a_v$, причому гарантується найважливіша властивість:
$$a_v < v$$
Тобто номер батька **завжди строго менший** за номер будь-якої його підпапки!

Антивірус запускається $k$ разів. Кожен запуск задається парою $(c_j, d_j)$: сканування починається у папці $c_j$ і розповсюджується на глибину до $d_j$ рівнів униз по дереву каталогу (тобто папка $c_j$ сканується з силою $d_j$, її прямі діти з силою $d_j - 1$, онуки — $d_j - 2$, і так далі, поки сила $\ge 0$).

**Що треба знайти:** Загальну кількість різних папок, які будуть перевірені хоча б одним запуском антивірусу.

---

### 2. Ручні крайові тести
1. **$n = 1, k = 1$, запуск $(1, 0)$:**  
   Лише корінь. Сканування глибиною $0$ перевіряє тільки папку $1$. Відповідь: $1$.
2. **Ланцюг $1 \to 2 \to 3 \to 4$, запуски $(1, 1)$ та $(2, 2)$:**  
   - Запуск $(1, 1)$ покриває $\{1, 2\}$.
   - Запуск $(2, 2)$ покриває $\{2, 3, 4\}$.
   - Усі 4 папки перевірено. Відповідь: $4$.
3. **Контрприклад для перезаписування:**  
   У папку $c=2$ зробили два запуски: спочатку з $d=5$, потім з $d=1$.  
   *Помилка наївного кодера:* перезаписати значення $b[2] = 1$ замість взяття максимуму $\max(5, 1) = 5$.

---

### 3. Аналіз лімітів і бюджет часу
- $n, k \le 2 \cdot 10^5$.
- Час виконання: 1.0 секунда.
- **Бюджет операцій:** $\approx 10^8$ операцій.
- Наївне моделювання кожного з $k$ запусків через DFS/BFS займає до $O(n \cdot k) \approx 4 \cdot 10^{10}$ операцій $\implies$ **Time Limit Exceeded (TLE)**!
- Необхідний оптимальний час: **$O(n + k)$** — лінійний прохід.
- Пам'ять: $O(n)$ для масивів батьків та максимальної сили сканування.

---

### 4. Вибір алгоритму з Mind Map
- [docs/ALGORITHM_DECISION_TREE.md](../../docs/ALGORITHM_DECISION_TREE.md) $\to$ **Trees & DAGs** $\to$ **Tree DP / Wave Propagation**:
  - Оскільки $a_v < v$, вершини **вже топологічно впорядковані** від $1$ до $n$!
  - Не потрібні ні рекурсивний DFS, ні побудова списків суміжності `adj[v]`.
  - Звичайний одновимірний прохід циклом `for (int v = 1; v <= n; ++v)`.

---

### 5. Доведення та Інваріант
Для кожної папки $v$ позначимо $b_v$ — найбільшу силу сканування, яку вона отримує безпосередньо від запусків у ній, або яка доходить до неї згори від батька $a_v$.

Математичне співвідношення:
$$b_v = \max\left(\max_{j: c_j = v} d_j, \; b_{a_v} - 1\right)$$

**Інваріант коректності:**
Оскільки $a_v < v$, коли цикл досягає індексу $v$, значення для його батька $b_{a_v}$ **вже повністю обчислене та фіналізоване**!
Тому хвиля сканування природно спускається від кореня до листків за один прохід без жодних рекурсій. Папка $v$ вважається перевіреною тоді й лише тоді, коли $b_v \ge 0$.

### 6. Двомовний код (C++20 та Python 3.12)
- C++20: [solution.cpp](file:///C:/project/super-algo/tasks/ucpc2026_stage1/problem_A_antivirus/solution.cpp)
- Python 3.12: [solution.py](file:///C:/project/super-algo/tasks/ucpc2026_stage1/problem_A_antivirus/solution.py)

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    int n, k;
    if (!(cin >> n >> k)) return 0;

    vector<int> a(n + 1, 0);
    for (int v = 2; v <= n; ++v) {
        cin >> a[v];
    }

    vector<int> b(n + 1, -1);
    for (int j = 0; j < k; ++j) {
        int c, d;
        cin >> c >> d;
        b[c] = max(b[c], d);
    }

    // Лінійний спуск завдяки властивості a[v] < v
    for (int v = 1; v <= n; ++v) {
        int p = a[v];
        if (p > 0 && b[p] > 0) {
            b[v] = max(b[v], b[p] - 1);
        }
    }

    int ans = 0;
    for (int v = 1; v <= n; ++v) {
        if (b[v] >= 0) ans++;
    }

    cout << ans << "\n";
    return 0;
}
```

### 7. Аудит граблів та людських помилок
- ❌ **Перезаписування запусків замість максимуму:** якщо для однієї папки $c$ є декілька запусків, треба брати $b[c] = \max(b[c], d)$, а не просто присвоювати $b[c] = d$.
- ❌ **Побудова явного графа через `vector<int> adj[N]`:** створює зайвий оверхед по пам'яті та кеш-промахи. Достатньо лише масиву батьків $a[v]$.
- ❌ **Ініціалізація нулем замість -1:** папка зі значенням $b=0$ **є перевіреною** (антивірус перевірив саме її, але не піде далі до дітей). Нескановані папки повинні мати значення $-1$.

### 8. Стрес-тест та командна стратегія
- **ICPC Тактика:**
  - *Аналітик:* звертає увагу на рядок в умові $a_v < v$ і одразу кричить: «Це топологічний порядок, граф будувати не треба!».
  - *Кодер:* пише 15 рядків коду за 3 хвилини.
  - *Тестер:* перевіряє випадки, коли глибина $d=0$, та коли кілька запусків потрапляють в одну вершину.
