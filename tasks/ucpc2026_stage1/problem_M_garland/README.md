# Problem M: Гірлянда UCPC (Garland UCPC)
**Турнір:** UCPC 2026. Stage I (Офіційний розбір: Сторінка 14)  
**Теги:** `Strings`, `Greedy`, `Two Pointers`, `Combinatorics`, `O(N)`  
**Складність:** Medium-Hard  

---

## ⚡ 8-Кроковий Золотий Стандарт Розбору

### 1. Вдупляння (Sense-Making)
Дано гірлянду довжиною $n$, що складається з ліхтарів, кожен з яких позначений однією з великих літер (наприклад, `U`, `C`, `P` тощо).  
Ми хочемо розфарбувати ліхтарі у 3 кольори (наприклад, червоний, зелений, синій) так, щоб кожне входження підпослідовності «`UCPC`» було розфарбоване **однаково**.

Тобто, якщо послідовність ліхтарів $i_1 < i_2 < i_3 < i_4$ утворює слово `UCPC` ($s[i_1] = \text{'U'}, s[i_2] = \text{'C'}, s[i_3] = \text{'P'}, s[i_4] = \text{'C'}$), то четвірка їх кольорів $(c[i_1], c[i_2], c[i_3], c[i_4])$ має бути однаковою для абсолютно всіх таких четвірок у гірлянді:
$$(c_1, c_2, c_3, c_4)$$

**Що треба знайти:** Кількість таких узгоджених розфарбувань за модулем $10^9 + 7$.

---

### 2. Ручні крайові тести
1. **Немає жодного слова «UCPC» (наприклад, $s = \text{"UUUU"}$):**  
   Жодних обмежень на кольори ліхтарів немає! Кожен з $n$ ліхтарів може незалежно мати будь-який з 3 кольорів.  
   Відповідь: $3^n \bmod (10^9 + 7)$.
2. **Єдине слово «UCPC» ($n=4$):**  
   Ліхтарі $0, 1, 2, 3$ грають ролі $1, 2, 3, 4$. Вільних ліхтарів немає ($f=0$). Оскільки $s[1]$ та $s[3]$ — це різні ліхтарі, але $L_4 = 3 > R_2 = 1$ (немає спільного ліхтаря), ролі 2 та 4 отримують кольори $c_2$ та $c_4$ незалежно.  
   Відповідь: $3^{0+4} = 3^4 = 81$.
3. **Ліхтар грає обидві ролі 2 і 4 (контрприклад):**  
   Рядок `UCPCUCPC`: лампа на позиції 3 може бути кінцем першого `UCPC` (роль 4) і початком другого (роль 2). Тоді колір другої літери 'C' мусить збігатися з кольором четвертої літери 'C' ($c_2 = c_4$). Кількість варіантів кольорів для літер скорочується з $3^4$ до $3^3 = 27$!

### 3. Аналіз лімітів і бюджет часу
- $n \le 2 \cdot 10^5$.
- Час виконання: 1.0 секунда.
- Перебір усіх розфарбувань $3^n$ неможливий ($3^{200000} \ggg 10^8$).
- Потрібен лінійний алгоритм: **$O(n)$** за часом та $O(n)$ за пам'яттю.

### 5. Доведення та Інваріант
Скажімо, що лампа $i$ **грає роль $j$** ($1 \le j \le 4$), якщо вона може бути $j$-ю літерою в деякому входженні слова `UCPC`.  
Лампу, яка не бере участі в жодному входженні `UCPC`, назвемо **вільною**.

**Властивість жадібного збігу:**
Лампа $i$ з відповідною літерою грає роль $j$ тоді й лише тоді, коли:
$$L_j \le i \le R_j$$
Усі вільні лампи (нехай їх кількість дорівнює $f$) можуть бути пофарбовані у будь-який з 3 кольорів абсолютно незалежно ($3^f$ варіантів).

Тепер розглянемо фіксовані ролі $1, 2, 3, 4$:
- Літери `U`, `C`, `P` різні, тому жодна лампа не може одночасно грати роль з різними літерами.
- Єдині дві ролі з однаковою літерою — це роль 2 (`C`) та роль 4 (`C`).
- Лампа може одночасно грати і роль 2, і роль 4 тоді й лише тоді, коли інтервали перетинаються:
$$L_4 \le R_2$$

**Формула відповіді:**
1. Якщо «`UCPC`» взагалі не утворюється ($L_4 = -1$):
   $$\text{Ans} = 3^n \pmod{10^9 + 7}$$
2. Якщо деяка лампа грає обидві ролі 2 і 4 ($L_4 \le R_2$):
   Колір ролі 2 зобов'язаний дорівнювати кольору ролі 4 ($c_2 = c_4$). Залишається 3 незалежні кольори для букв $(c_1, c_2, c_3)$, тому:
   $$\text{Ans} = 3^{f + 3} \pmod{10^9 + 7}$$
3. Якщо ролі 2 і 4 не мають спільної лампи ($L_4 > R_2$):
   Всі 4 кольори $(c_1, c_2, c_3, c_4)$ обираються незалежно:
   $$\text{Ans} = 3^{f + 4} \pmod{10^9 + 7}$$

### 6. Двомовний код (C++20 та Python 3.12)
- C++20: [solution.cpp](file:///C:/project/super-algo/tasks/ucpc2026_stage1/problem_M_garland/solution.cpp)
- Python 3.12: [solution.py](file:///C:/project/super-algo/tasks/ucpc2026_stage1/problem_M_garland/solution.py)

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MOD = 1e9 + 7;

long long power3(long long exp) {
    long long res = 1, base = 3;
    while (exp > 0) {
        if (exp % 2 == 1) res = (res * base) % MOD;
        base = (base * base) % MOD;
        exp /= 2;
    }
    return res;
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    string s;
    if (!(cin >> s)) return 0;
    int n = s.size();
    const string target = "UCPC";

    // 1. Жадібний прохід зліва
    vector<int> L(4, -1);
    int cur = 0;
    for (int i = 0; i < n; ++i) {
        if (cur < 4 && s[i] == target[cur]) {
            L[cur++] = i;
        }
    }

    if (L[3] == -1) {
        cout << power3(n) << "\n";
        return 0;
    }

    // 2. Жадібний прохід справа
    vector<int> R(4, -1);
    cur = 3;
    for (int i = n - 1; i >= 0; --i) {
        if (cur >= 0 && s[i] == target[cur]) {
            R[cur--] = i;
        }
    }

    // 3. Вільні лампи
    int free_lamps = 0;
    for (int i = 0; i < n; ++i) {
        bool is_role = false;
        for (int j = 0; j < 4; ++j) {
            if (s[i] == target[j] && i >= L[j] && i <= R[j]) {
                is_role = true;
                break;
            }
        }
        if (!is_role) free_lamps++;
    }

    // 4. Перевірка перетину ролей 2 та 4
    bool clash = (L[3] <= R[1]);
    long long ans = clash ? power3(free_lamps + 3) : power3(free_lamps + 4);

    cout << ans << "\n";
    return 0;
}
```

### 7. Аудит граблів та людських помилок
- ❌ **Галюцинація додавання замість показника степеня:** Поширена помилка — написати $3^f + 3$ або $3^f + 4$ замість $3^{f+3}$ та $3^{f+4}$! Кожен додатковий ступінь свободи **множить** кількість комбінацій на 3, а не додає 3.
- ❌ **Відповідь 0 при відсутності слова UCPC:** Якщо слова немає взагалі, жодних обмежень на послідовність кольорів немає, тому відповідь не $0$, а $3^n$!
- ❌ **Строга нерівність замість нестрогої:** Перевірка перетину $L_4 \le R_2$ має бути саме **нестрогою** ($\le$), адже одна лампа може грати обидві ролі, якщо вона потрапляє в обидва діапазони.
