## ⚡ 8-Кроковий Золотий Стандарт Розбору

### 1. Вдупляння (Sense-Making)
Умови танцю: дано три додатні цілі числа $n, m, k$.  
Ми вибираємо трійку цілих чисел $(a, b, c)$, таку що:
$$1 \le a \le n, \quad 1 \le b \le m, \quad 1 \le c \le k$$

Танець називається **гармонійним**, якщо остача від ділення $a$ на $b$, $b$ на $c$, і $c$ на $a$ однакова:
$$a \bmod b = b \bmod c = c \bmod a = r$$

**Що треба знайти:** Кількість таких гармонійних трійок $(a, b, c)$.

---

### 2. Ручні крайові тести
1. **$n = 1, m = 1, k = 1$:**  
   Єдина трійка $(1, 1, 1)$.  
   $1 \bmod 1 = 0$, $1 \bmod 1 = 0$, $1 \bmod 1 = 0$. Усі остачі рівні $0$. Відповідь: $1$.
2. **$n = 3, m = 5, k = 4$:**  
   Підходять лише трійки однакових чисел $(1, 1, 1)$, $(2, 2, 2)$, $(3, 3, 3)$. Відповідь: $\min(3, 5, 4) = 3$.
3. **Контрприклад до припущення про різні числа:**  
   Спробуємо знайти різні $a, b, c$, наприклад $(2, 3, 4)$:  
   $2 \bmod 3 = 2$, $3 \bmod 4 = 3$, $4 \bmod 2 = 0$. Остачі різні ($2 \ne 3 \ne 0$) $\implies$ не підходить!

### 5. Доведення та Інваріант
Нехай $r$ — спільна остача:
$$r = a \bmod b < b, \quad r = b \bmod c < c, \quad r = c \bmod a < a$$
Остача завжди строго менша за дільник. Отже, число $r$ повинно бути строго меншим за кожне з чисел $a, b, c$:
$$r < a, \quad r < b, \quad r < c$$

Припустимо від супротивного, що $a < b$.  
Якщо $a < b$, то за означенням остачі $a \bmod b = a$.  
Але тоді $r = a$, що суперечить умові $r < a$!  
Отже, наше припущення неправильне, і обов'язково має виконуватися:
$$a \ge b$$

Аналогічно, якщо розглянути рівності $b \bmod c$ та $c \bmod a$:
$$b \ge c \quad \text{та} \quad c \ge a$$

Об'єднуючи ці три нерівності в кільце:
$$a \ge b \ge c \ge a \implies a = b = c$$

**Висновок:** Гармонійний танець можливий **тоді й лише тоді**, коли всі три числа рівні між собою: $a = b = c = x$.  
У цьому випадку:
$$x \bmod x = 0$$
Тобто спільна остача $r = 0$, і всі три рівності виконуються завжди!  
Оскільки $1 \le x \le n$, $1 \le x \le m$, $1 \le x \le k$, кількість таких трійок дорівнює:
$$\min(n, m, k)$$

def solve():
    data = sys.stdin.read().split()
    if not data:
        return
    n, m, k = int(data[0]), int(data[1]), int(data[2])
    print(min(n, m, k))
