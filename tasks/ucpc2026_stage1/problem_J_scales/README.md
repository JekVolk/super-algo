## ⚡ 8-Кроковий Розбір Задачі

### 1. Вдупляння (Sense-Making)
Журі загадало два таємних $n$-бітних невід'ємних цілих числа $a$ та $b$.  
Ви не знаєте їхніх значень. Проте ви можете робити запити до "терезів":  
Надіславши пару чисел $(x, y)$, ви отримуєте результат порівняння:
- `>` якщо $(a \oplus x) > (b \oplus y)$;
- `<` якщо $(a \oplus x) < (b \oplus y)$;
- `=` якщо $(a \oplus x) == (b \oplus y)$.  
Ваша мета — відгадати обидва числа $a$ та $b$, використавши **не більше ніж $2n$ зважувань**!  
Після з'ясування чисел потрібно вивести рядок `! a b`.

---

### 2. Ручні крайові тести
1. **$n = 1$, $a = 0, b = 0$:**  
   Запит $(0, 0) \implies =$. Спільний біт.  
   Запит $(1, 0)$ інвертує біт $a$. Отримуємо $(1, 0) \implies >$. Отже, біт $a$ був 0, біт $b$ був 0. Виводимо `! 0 0`.
2. **$n = 1$, $a = 1, b = 0$:**  
   Запит $(0, 0) \implies >$. Різні біти. Оскільки це останній біт і результат $>$, то $a = 1, b = 0$. Виводимо `! 1 0`.

---

### 3. Аналіз лімітів і бюджет часу
- $n \le 60$ біт (числа вміщуються у стандартні 64-бітні цілі `unsigned long long`).
- Максимум $2n$ зважувань.
- Час на запит: $O(1)$. Загальний час $O(n)$ — долі мілісекунди.
- Обов'язковий `flush` буфера виводу після кожного запиту.

### 5. Доведення та Інваріант
Результат порівняння двох двійкових чисел визначається **найстаршим бітом, у якому вони відрізняються**.  
Відновлюватимемо біти згори донизу від $j = n-1$ до $0$.  
Нехай старші біти вище за $j$ уже відомі. Тоді ми можемо скомпенсувати їх, передаючи відомі біти у $x$ та $y$, тож вони скорочуються!  
Підтримуємо інваріант $c$ — поточне відношення між невідомими хвостами $a$ та $b$.  
Спочатку робимо запит $(0, 0)$ для отримання початкового $c$.  
На кожному біті $j$:
1. **Якщо $c$ дорівнює `=`:**  
   Це означає, що всі біти від $j$ до 0 в обох числах ідентичні!  
   Робимо одне зважування з інверсією біта $j$ в $a$. Тепер числа відрізняються лише у цьому єдиному біті!  
   Якщо відповідь `>`, то біт $a$ був $0$ (став $1$), отже $a_j = 0, b_j = 0$.  
   Якщо `<`, то біт $a$ був $1$ (став $0$), отже $a_j = 1, b_j = 1$.  
   Стан $c$ лишається `=`. Витрачено лише 1 зважування!
2. **Якщо $c$ не дорівнює `=`:**  
   Робимо два зважування: $r_1$ для інверсії біта $j$ в $a$, і $r_2$ для інверсії біта $j$ в $b$.  
   - Якщо $r_1 \ne r_2$: інвертований біт є найстаршою відмінністю, тому $a_j \ne b_j$. Тоді $r_1$ безпосередньо показує, у кого одиниця, а $c$ стає рівним $r_1$.  
   - Якщо $r_1 == r_2$: біти однакові ($a_j == b_j$). Інверсія робить їх рівними, і обидві відповіді дорівнюють порівнянню нижчих бітів. Новим станом $c$ стає $r_1$.  
На наймолодшому біті $j = 0$, якщо $c \ne {=}$, зважування взагалі не потрібне — знак $c$ прямо вказує на значення біта!  
Загальна кількість зважувань гарантовано $\le 2n$.
