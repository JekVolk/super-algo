## ⚡ 8-Кроковий Розбір Задачі

### 1. Вдупляння (Sense-Making)

#### 🍎 ELI5 — Пояснення для 10-річної дитини

Уяви, що у тебе є скарбничка з монетками різного номіналу, і ти забув, які саме монетки лежать всередині. Але тобі пощастило: кожного разу, коли ти брав **будь-яку групу монеток**, ти записував у блокнот **два числа**:
1. **Суму** цих монеток (скільки грошей всього).
2. **"Маску"** (побітове АБО) — число, яке показує, які «типи» монеток зустрічались хоч раз.

Потім ти всі ці числа виписав у один рядок і **перемішав** їх. Задача: **відновити початковий список монеток** тільки з цього перемішаного рядка.

---

#### 🎯 Формальне формулювання

| Компонент | Опис |
|-----------|------|
| **Об'єкти** | Відсортований масив $a_1 \le a_2 \le \dots \le a_n$ цілих додатних чисел |
| **Операції** | Для кожної непорожньої підмножини $S$ обчислюються: $\text{sum}(S) = \sum_{i \in S} a_i$ та $\text{or}(S) = \text{OR}_{i \in S} a_i$ |
| **Ціль** | За відсортованим об'єднанням усіх $2 \cdot (2^n - 1)$ показів відновити початковий масив $a$ |

### 2. Ручні крайові тести

#### Тест 1: $n = 1$, масив $[5]$

- Є лише одна підмножина $\{1\}$: $\text{sum} = 5$, $\text{OR} = 5$.  
- Журнал (відсортований): $[5,\ 5]$.  
- **Покрокове міркування:** найменший елемент журналу — $5$. Він не «пояснений» жодною попередньою підмножиною, отже $a_1 = 5$. Відновлено $n = 1$ елемент — стоп.  
- **Відповідь:** `5`

---

#### Тест 2: $n = 2$, масив $[3, 5]$

Підмножини і їх покази:

| Підмножина $S$ | $\text{sum}$ | $\text{OR}$ |
|----------------|-------------|-------------|
| $\{1\}$ | 3 | 3 |
| $\{2\}$ | 5 | 5 |
| $\{1,2\}$ | 8 | $3 \mid 5 = 7$ |

Журнал (відсортований): $[3,\ 3,\ 5,\ 5,\ 7,\ 8]$

**Покрокове міркування:**
1. Мін-купа порожня. Читаємо $3$ → не пояснено → $a_1 = 3$.  
   Генеруємо нові покази від одноелементної підмножини $\{a_1\}$: у купу $\{3, 3\}$; одразу витягуємо один $3$ (бо поточний $3$ вже пояснений).  
   Купа: $\{3\}$.
2. Читаємо наступний $3$ → вершина купи $= 3$ → **пояснено**, витягуємо.  
   Купа: $\{\}$.
3. Читаємо $5$ → купа порожня → $a_2 = 5$. Маємо $n = 2$ елементи — стоп.
- **Відповідь:** `3 5`

---

#### Тест 3: $n = 2$, масив $[2, 2]$

Підмножини:

| $S$ | $\text{sum}$ | $\text{OR}$ |
|-----|-------------|-------------|
| $\{1\}$ | 2 | 2 |
| $\{2\}$ | 2 | 2 |
| $\{1,2\}$ | 4 | $2 \mid 2 = 2$ |

Журнал: $[2,\ 2,\ 2,\ 2,\ 2,\ 4]$

**Покрокове міркування:**
1. Читаємо $2$ → купа порожня → $a_1 = 2$.  
   Нові покази: $\text{sum} = 0 + 2 = 2$, $\text{OR} = 0 \mid 2 = 2$. Кладемо обидва $2$ у купу, витягуємо один $2$.  
   Купа: $\{2\}$.
2. Читаємо $2$ → вершина $= 2$ → **пояснено**, витягуємо. Купа: $\{\}$.
3. Читаємо $2$ → купа порожня → $a_2 = 2$. Маємо $n = 2$ — стоп.
- **Відповідь:** `2 2`

---

#### Тест 4: $n = 3$, масив $[1, 4, 6]$

Підмножини ($7$ штук) породжують $14$ показів. Після сортування журнал починається з $[1, 1, 4, 4, 5, 5, 6, 6, 7, 7, 10, 11, 11, 11]$.

**Покрокове міркування (скорочено):**
1. $1$ → купа порожня → $a_1 = 1$. Купа після: $\{1\}$.
2. $1$ → пояснено. Купа: $\{\}$.
3. $4$ → $a_2 = 4$. Нові покази від $\{1,4\}$: $\text{sum}=5$, $\text{OR}=5$. Купа після витягування: $\{4, 5, 5\}$.  
   *(одноелементна підмножина $\{4\}$ дала $4, 4$; комбінація $\{1,4\}$ — $5, 5$; поточний $4$ витягується)*
4. $4$ → пояснено. Купа: $\{5, 5\}$.
5. $5$ → пояснено. Купа: $\{5\}$.
6. $5$ → пояснено. Купа: $\{\}$.
7. $6$ → $a_3 = 6$. Маємо $n = 3$ — стоп.
- **Відповідь:** `1 4 6`

### 3. Аналіз лімітів і бюджет часу

| Параметр | Обмеження |
|----------|-----------|
| $n$ | $\le 16$ |
| Кількість показів | $2 \cdot (2^n - 1) \le 131\,070$ |
| $a_i$ | $\le 10^9$ |
| Складність | $O(2^n \cdot n)$ для генерації + $O(2^n \log 2^n)$ для мін-купи |
| Пам'ять | $O(2^n)$ для масивів $\text{subsets\_sum}$ та $\text{subsets\_or}$ |

### 5. Доведення та Інваріант

#### 📐 Ключове математичне спостереження

Для будь-якої непорожньої підмножини $S$ додатних цілих чисел виконуються нерівності:

$$\text{sum}(S) = \sum_{i \in S} a_i \ge \max_{i \in S} a_i$$

$$\text{OR}(S) = \text{OR}_{i \in S} a_i \ge \max_{i \in S} a_i$$

(OR не може «втратити» старший біт, а отже не зменшує максимальний елемент.)

#### 📋 Псевдокод (7 кроків, мовою людини)

```
1. Відсортувати журнал показів b за зростанням.
2. Підготувати порожню мін-купу «пояснених» значень.
3. Зберігати списки subsets_sum = [0] та subsets_or = [0]
   (фіктивна «порожня підмножина» зі sum=0, OR=0).
4. Для кожного значення val у журналі (зліва направо):
   а) Якщо вершина купи == val → значення «пояснено»:
      витягнути з купи та пропустити.
   б) Інакше → val є новим елементом x = a[k+1]:
      - Для кожної вже відомої підмножини (s, o) з subsets:
          * Обчислити ns = s + x, no = o | x
          * Покласти ns і no у мін-купу (вони будуть «пояснені»)
      - Витягнути зі купи один екземпляр x
        (він відповідає поточному val з журналу)
      - Оновити списки subsets_sum і subsets_or новими ns, no.
5. Зупинитись, коли відновлено n елементів.
```

#### 💥 Чому наївний підхід ламається?

| Наївна ідея | Де ламається |
|-------------|-------------|
| Спробувати всі можливі масиви перебором | $O(10^9)^n$ — нереально навіть для $n=2$ |
| Взяти перші $n$ елементів із журналу як відповідь | Ігнорує те, що кожен елемент зустрічається двічі (sum і OR для одноелементної підмножини однакові) |
| Видаляти пояснені значення через `set` (множину) | Не підтримує дублікати: два однакових значення (напр. $2, 2$) видаляться разом, хоча мали б бути вилучені по одному |
| Зберігати тільки суми підмножин (без OR) | Пропускає пояснення показів від OR, і алгоритм «бачить» хибні нові елементи |

### 6. Двомовний код

#### 🐍 Python (`solution.py`)

```python
import sys
import heapq

def solve_f(n: int, b: list[int]) -> list[int]:
    # Крок 1: відсортувати всі покази
    b.sort()

    # Мін-купа "пояснених" значень, які ще не були зіставлені з журналом
    heap = []

    # Відновлений масив
    a = []

    # Підмножини, відомі на цей момент (сума і OR).
    # Стартуємо з "порожньої підмножини": sum=0, OR=0
    subsets_sum = [0]
    subsets_or  = [0]

    for val in b:
        if heap and heap[0] == val:
            # Значення val вже "пояснено" попереднім елементом — прибираємо
            heapq.heappop(heap)
        else:
            # val не пояснено → це наступний елемент масиву
            x = val
            a.append(x)
            if len(a) == n:
                break  # Відновили всі n елементів — зупиняємось

            # Генеруємо нові покази від усіх підмножин, розширених x
            new_sums = []
            new_ors  = []
            for s, o in zip(subsets_sum, subsets_or):
                ns = s + x       # нова сума підмножини ∪ {x}
                no = o | x       # новий OR підмножини ∪ {x}
                new_sums.append(ns)
                new_ors.append(no)
                # Кладемо обидва покази у "пояснені"
                heapq.heappush(heap, ns)
                heapq.heappush(heap, no)

            # Один екземпляр x (від одноелементної підмножини {x})
            # відповідає поточному val — витягуємо його з купи
            heapq.heappop(heap)

            # Оновлюємо списки підмножин (подвоєння: старі + нові)
            subsets_sum.extend(new_sums)
            subsets_or.extend(new_ors)

    return a

def main():
    input_data = sys.stdin.read().split()
    if not input_data:
        return
    idx = 0
    while idx < len(input_data):
        n = int(input_data[idx])
        idx += 1
        # Кількість показів: 2 * (2^n - 1)
        num_elements = 2 * ((1 << n) - 1)
        b = [int(input_data[idx + i]) for i in range(num_elements)]
        idx += num_elements
        res = solve_f(n, b)
        print(*res)

if __name__ == "__main__":
    main()
```

#### ⚡ C++ (`solution.cpp`)

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <algorithm>

using namespace std;

void solve_one(int n, vector<long long>& b) {
    // Крок 1: відсортувати журнал показів
    sort(b.begin(), b.end());

    // Мін-купа "пояснених" значень (priority_queue з greater → мін-купа)
    priority_queue<long long, vector<long long>, greater<long long>> pq;

    vector<long long> a;               // відновлений масив
    vector<long long> subsets_sum = {0}; // суми підмножин (порожня = 0)
    vector<long long> subsets_or  = {0}; // OR підмножин (порожня = 0)

    for (long long val : b) {
        if (!pq.empty() && pq.top() == val) {
            // Значення вже "пояснено" — прибираємо з купи
            pq.pop();
        } else {
            // Новий елемент масиву
            long long x = val;
            a.push_back(x);
            if ((int)a.size() == n) {
                break; // Відновили всі n елементів
            }

            size_t m = subsets_sum.size();
            vector<long long> new_sums(m);
            vector<long long> new_ors(m);

            // Генеруємо нові покази від усіх підмножин, розширених x
            for (size_t i = 0; i < m; ++i) {
                long long ns = subsets_sum[i] + x; // нова сума
                long long no = subsets_or[i]  | x; // новий OR
                new_sums[i] = ns;
                new_ors[i]  = no;
                pq.push(ns); // кладемо в "пояснені"
                pq.push(no);
            }

            // Витягуємо один x (він відповідає поточному val з журналу)
            pq.pop();

            // Подвоюємо списки підмножин
            for (size_t i = 0; i < m; ++i) {
                subsets_sum.push_back(new_sums[i]);
                subsets_or.push_back(new_ors[i]);
            }
        }
    }

    // Виводимо відповідь
    for (size_t i = 0; i < a.size(); ++i) {
        cout << a[i] << (i + 1 == a.size() ? "" : " ");
    }
    cout << "\n";
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    int n;
    while (cin >> n) {
        int m = 2 * ((1 << n) - 1); // кількість показів
        vector<long long> b(m);
        for (int i = 0; i < m; ++i) {
            cin >> b[i];
        }
        solve_one(n, b);
    }
    return 0;
}
```

### 7. Аудит граблів та людських помилок

#### ❌ Грабля 1: Видалення дублікатів через `set` замість мультимножини

```python
# НЕПРАВИЛЬНО:
explained = set()
if val in explained:
    explained.remove(val)  # видалить ВСІ входження!
```

💥 **Наслідок:** При масиві $[2, 2]$ обидва $2$ видаляться одразу, і алгоритм «вирішить», що $a_2 = 4$ — **WA**.  
✅ **Правило:** Використовуй мін-купу (`heapq`) або `collections.Counter`, щоб рахувати кратності окремо.

---

#### ❌ Грабля 2: Не витягувати val із купи після знаходження нового елемента

```python
# НЕПРАВИЛЬНО: після a.append(x) одразу не pop():
heapq.heappush(heap, ns)
heapq.heappush(heap, no)
# ← забули heapq.heappop(heap) для поточного val
```

💥 **Наслідок:** Один зайвий «пояснений» $x$ зависне в купі та буде видалений замість справжнього нового елемента → **WA** на кожному тесті з $n \ge 2$.  
✅ **Правило:** Кожного разу, коли знайдено новий елемент $x$, витягти рівно один екземпляр $x$ з купи (він відповідає поточному `val` з журналу).

---

#### ❌ Грабля 3: Використання `int` замість `long long` у C++

```cpp
// НЕПРАВИЛЬНО:
int subsets_sum[...]; // переповнення при a_i до 10^9 і n=16
```

💥 **Наслідок:** При $n = 16$ сума всіх елементів може сягати $16 \times 10^9 > 2^{32}$ → переповнення `int` → **WA** або **RE**.  
✅ **Правило:** Завжди використовуй `long long` для сум і OR.

---

#### ❌ Грабля 4: Зупинитися занадто рано (не обробити останній елемент)

```python
# РИЗИК: умова break стоїть ДО генерації нових показів
if len(a) == n:
    break  # ← правильно: нам більше не треба генерувати показів
```

💥 **Наслідок:** Якщо помилково поставити `break` після генерації, зайві значення потраплять у купу, але це лише марна робота. Якщо поставити `break` до `a.append(x)` — **WA**, втрачаємо останній елемент.  
✅ **Правило:** Спочатку `a.append(x)`, потім перевірка `if len(a) == n: break`. Генерацію нових показів робити тільки якщо $n$ ще не досягнуто.

```python
# stress_tester.py
import random
import subprocess
import sys

def generate_input(n, max_val=100):
    """Генерує відсортований масив з n елементів і будує з нього журнал."""
    orig = sorted(random.randint(1, max_val) for _ in range(n))
    all_vals = []
    for mask in range(1, 1 << n):
        subset = [orig[i] for i in range(n) if mask & (1 << i)]
        s = sum(subset)
        o = 0
        for v in subset:
            o |= v
        all_vals.extend([s, o])
    all_vals.sort()
    inp = f"{n}\n" + " ".join(map(str, all_vals))
    expected = " ".join(map(str, orig))
    return inp, expected

def run_solution(inp):
    p = subprocess.run(
        [sys.executable, "solution.py"],
        input=inp, text=True, capture_output=True
    )
    return p.stdout.strip()

if __name__ == "__main__":
    NUM_TESTS = 500
    passed = 0
    for t in range(NUM_TESTS):
        n = random.randint(1, 6)          # малі n для швидкості
        inp, expected = generate_input(n, max_val=50)
        got = run_solution(inp)
        if got != expected:
            print(f"❌ FAIL на тесті #{t+1}:")
            print(f"   Вхід: {inp}")
            print(f"   Очікувано: {expected}")
            print(f"   Отримано:  {got}")
            sys.exit(1)
        else:
            passed += 1
    print(f"✅ Всі {passed}/{NUM_TESTS} стрес-тестів пройдено!")
```
