## ⚡ 8-Кроковий Розбір Задачі

### 1. Вдупляння (Sense-Making)
Вам дано одне дійсне число $s$.  
Потрібно підібрати якомога меншу кількість дійсних чисел $n$ ($n \ge 1$) і самі ці числа $a_1, a_2, \dots, a_n$ такі, що:
1. Їхня сума дорівнює $s$: $a_1 + a_2 + \dots + a_n = s$;
2. Їхній добуток дорівнює 1: $a_1 \cdot a_2 \cdot \dots \cdot a_n = 1$.  
Вивести $n$, а потім самі числа через пробіл із високою точністю.

---

### 2. Ручні крайові тести
1. **$s = 1$:** Достатньо одного числа $a_1 = 1$. Сума 1, добуток 1. Відповідь: $n = 1$, числа $[1.0]$.
2. **$s = 2$:** Одне число не підходить ($s \ne 1$). Спробуємо $n = 2$: $a_1 = 1, a_2 = 1$. Сума $1+1=2$, добуток $1\cdot 1=1$. Відповідь: $n = 2$, числа $[1.0, 1.0]$.
3. **$s = 0$:** $n=1$ неможливо. $n=2$: $a_1 a_2 = 1 \implies a_1 + a_2 = a_1 + 1/a_1 \ge 2$ або $\le -2$, тому 0 отримати не можна! Потрібно $n = 3$: візьмемо $a_1 = -1$, тоді $a_2 + a_3 = 1$ та $a_2 a_3 = -1$. Числа: $[-1, \frac{1+\sqrt{5}}{2}, \frac{1-\sqrt{5}}{2}]$. Добуток: $(-1)(-1) = 1$, сума: $-1 + 1 = 0$. Відповідь: $n = 3$.

---

### 3. Аналіз лімітів і бюджет часу
- $|s| \le 10^9$.
- Час на одне число: $O(1)$.
- Високі вимоги до точності: при великих $|s|$ пряме віднімання $\sqrt{s^2 - 4}$ призводить до втрати значущих цифр (catastrophic cancellation). Потрібно обчислювати більший корінь через додавання, а менший — як $1/y$.

### 5. Доведення та Інваріант
1. **$n = 1$:** Можливо тоді й лише тоді, коли $s = 1$ (бо $a_1 = s$ та $a_1 = 1$).
2. **$n = 2$:** Числа задовольняють $a_1 + a_2 = s$ та $a_1 a_2 = 1$. За теоремою Вієта це корені квадратного рівняння:
   $$t^2 - st + 1 = 0.$$
   Дискримінант $D = s^2 - 4$. Корені є дійсними тоді й лише тоді, коли $D \ge 0 \iff |s| \ge 2$.  
   Отже, при $|s| \ge 2$ (і $s \ne 1$) відповідь завжди $n = 2$!
3. **$n = 3$ для всіх інших $s$ ($|s| < 2$ та $s \ne 1$):**  
   Оскільки $|s| < 2$, двох чисел не вистачить ($a_1 + 1/a_1$ за модулем завжди $\ge 2$).  
   Проте трьох чисел завжди достатньо: зафіксуємо $a_1 = -1$.  
   Тоді для решти двох чисел потрібно:
   $$a_2 + a_3 = s + 1, \quad a_2 \cdot a_3 = -1.$$  
   Це корені рівняння $t^2 - (s+1)t - 1 = 0$.  
   Його дискримінант $D = (s+1)^2 + 4 > 0$ **завжди строго додатний** для будь-якого дійсного $s$!  
   Добуток трьох чисел: $a_1 \cdot (a_2 a_3) = (-1) \cdot (-1) = 1$.  
   Сума трьох чисел: $a_1 + (a_2 + a_3) = -1 + (s + 1) = s$.  
   Рішення завжди існує і шукається аналітично за $O(1)$!

### 7. Аудит граблів та людських помилок
- **Втрата точності (Catastrophic Cancellation):** Якщо при великому $s$ рахувати менший корінь як $(s - \sqrt{s^2-4})/2$, ви віднімаєте два майже однакових числа і втрачаєте точність. Треба рахувати $y = \text{sgn}(s)(|s| + \sqrt{s^2-4})/2$, а другий корінь як $1/y$.
