Оберіть або введіть ліміт $N$ задачі:
Швидкі пресети:

1. Дерева з властивістю $a_v < v$

Чому це чит-код: Якщо батько папки/вузла завжди має менший номер за дитину ($a_v < v$), дерево вже топологічно впорядковане!

for (int v = 1; v ≤ n; ++v)
  b[v] = max(b[v], b[parent[v]] - 1);

Граф обробляється за один звичайний лінійний цикл $O(N)$ без створення списків суміжності, DFS чи стеків рекурсії!

2. Meet-in-the-Middle & Два Вказівники

Суть розбиття 4 = 2 + 2: Перебір 4 чисел вимагає $O(N^4) \approx (2000)^4 = 1.6 \cdot 10^{13}$ (безнадійне TLE). Але розбивши на попарні суми $P = \{a_i + a_j\}$, їх розмір лише $S \approx \frac{N^2}{2} \approx 2 \cdot 10^6$.

Відсортувавши $P$ за $O(S \log S)$, шукаємо $P_L + P_R \le M$ двома вказівниками за лінійний час $O(S)$. Загальний час: $O(N^2 \log N)$!

3. Кругові Масиви ($2N$) та Binary Lifting

Трюк з ножицями: Коло не має фіксованого початку. Дуги на кшталт $[7, 2]$ перетинають нуль. Розгортаємо стіл двічі: $[1 \dots 2n]$. Кожна дуга стає звичайним відрізком на прямій!

Замість лінійного обходу будуємо масив $nxt[k][v]$ (стрибок на $2^k$ відрізків). Кожен запит вирішується за $O(\log n)$ замість $O(n)$!

4. Теорія Чисел & Інваріанти Залишків

Круг остач: Якщо $a \pmod b = b \pmod c = c \pmod a$, то через властивості ділення обов'язково $a \ge b \ge c \ge a \implies a = b = c$. Залишок дорівнює $0$, а відповідь: $\min(N, M, K)$ за $O(1)$.

Числа Харшада (сусіди $x, x+1$): Число $x = c \cdot 10^B$ має суму цифр 8 (ділиться на 8), а $x+1$ має суму 9 (ділиться на 9). Конструкція знаходить пару за $O(|m|)$.

5. Мін-Купи & Мультимножини Підмножин

Детективний метод: Будь-яка сума чи OR підмножини ≥ за її мінімальний елемент. Тому перший же невідомий елемент у відсортованому журналі — це нове базове число $a_{k+1}$!

Додаємо нові покази у мін-купу (`std::priority_queue`). Потім просто знімаємо відомі покази з купи. Складність строго $O(2^n \cdot n)$.

6. Min-Cost Max-Flow на DAG (3 Комп'ютери)

Планування процесів: Розподілити відрізки з вагами між $K=3$ паралельними машинами. Жадібний вибір зазнає поразки. Але в потоковій мережі:

Ребра часу мають ємність 3 і вартість 0. Ребра задач мають ємність 1 і вартість $-w_i$. Пускаємо рівно 3 одиниці потоку через 3 запуски Дейкстри з потенціалами за $O(n \log n)$!

7. Бордери Рядків та Лінійне ДП $O(N)$

Бордер слова: Префікс, який водночас є суфіксом. Формула для кількості слів без бордерів $u(n)$ скорочується телескопічно:

u(2m+1) = k · u(2m)
u(2m) = k · u(2m-1) - u(m) (mod 10⁹ + 7)

Замість важкого перебору всіх дільників $O(N^2)$ маємо чисте лінійне ДП за $O(N)$!

8. Графи Станів та Ейлеровий Ланцюг

Закон збереження переходів: У графі з двох станів (Сонце $\leftrightarrow$ Дощ) вихід $S \to R$ ($u$) вимагає повернення $R \to S$ ($v$), щоб знову вийти. Тому неминуче:

|u - v| ≤ 1 та u + v + 1 + e + g == n

Послідовність днів конструюється за $O(1)$ без жодного графового пошуку.

Задача C: Танок залишків (Dance of Remainders)

Дано три числа $N, M, K$. Шукаємо кількість трійок $(a, b, c)$, де $a \le N, b \le M, c \le K$, для яких залишки ділення по колу однакові: $a \pmod b = b \pmod c = c \pmod a = r$.

Перебір 3 циклів: O(N·M·K) ❌ TLE
Формула: min(N, M, K) ✅ O(1)

Чому $a, b, c$ ЗОБОВ'ЯЗАНІ бути рівними? (Інтуїтивне доведення)

1
Залишок завжди менший за дільник:

Якщо $r = a \pmod b$, то $r < b$. Якщо $r = b \pmod c$, то $r < c$. Якщо $r = c \pmod a$, то $r < a$. Тобто спільний залишок $r$ строго менший за кожне з трьох чисел!

2
Що якби одне число було меншим за інше?

Уявімо, що $a < b$. Тоді залишок від ділення меншого на більше $a \pmod b$ дорівнює самому числу $a$! Виходить $r = a$. Але з пункту 1 ми знаємо, що $r < a$! Маємо $a < a$ — це абсурд і суперечність!

3
Єдиний вихід — всі числа однакові ($a = b = c = x$):

Коли $a = b = c = x$, то $x \pmod x = 0$. Усі три залишки дорівнюють 0! Значить, підходять ТІЛЬКИ трійки $(x, x, x)$, де $x$ не перевищує жодне з $N, M, K$. Тобто $1 \le x \le \min(N, M, K)$!

Фінальна формула для будь-яких N, M, K:
ans = min({n, m, k});
O(1) Час

Інтерактивний калькулятор

Список трійок: (1,1,1), (2,2,2), (3,3,3)

Задача E: Чотири числа (Four Numbers) — «Meet-in-the-Middle + Два Вказівники»

Обрати 4 елементи з масиву (елементи можна повторювати), щоб їхня сума була якомога більшою, але не перевищувала ліміт $M$.

4 вкладені цикли: O(N⁴) ❌ TLE
Попарні суми + 2Ptrs: O(N² log N) ✅ 100 балів

Анімація сходження двох вказівників (Left & Right)

Відсортований масив попарних сум: Ліміт $M$ = 30
Поточна сума: P[L] + P[R]. Натисніть «Крок», щоб почати пошук.

Інсайт: Розбиття 4 = 2 + 2

1. Замість перебору 4 елементів, ми рахуємо всі попарні суми $P_{x,y} = a_x + a_y$. Їх усього $S \approx \frac{N^2}{2}$.

2. Сортуємо їх за $O(S \log S)$.

3. Тепер шукаємо $P_L + P_R \le M$. Якщо сума $\le M$, оновлюємо максимум і рухаємо $L \to$ вправо. Якщо перевищує $M$, зменшуємо $R \leftarrow$ вліво!

// Два вказівники за O(N^2)
long long best = -1;
int l = 0, r = p.size() - 1;
while (l <= r) {
    if (p[l] + p[r] <= m) {
        best = max(best, p[l] + p[r]);
        l++;
    } else {
        r--;
    }
}

Рядок із літер. Знаходимо всі входження підпослідовності «UCPC». Лампи, що не входять у жодне UCPC, вважаються вільними. Скільки узгоджених розфарбувань існує?

Складність: O(N) 2 жадібні проходи
Візуалізація ролей ліхтарів у гірлянді:

Пояснення на пальцях (для чайників)

1. Хто такі «вільні лампи»?

Лампи, які не беруть участі в жодному слові UCPC. Вони нічим не обмежені! Кожна вільна лампа має 3 незалежні варіанти кольору ($3^f$).

2. Чому 2 проходи (L і R)?

Жадібний прохід зліва знаходить найраніші позиції літер, а справа — найпізніші. Будь-яка лампа між $L_j$ та $R_j$ з відповідною літерою грає свою роль!

3. Звідки беруться степені $3^{f+3}$ та $3^{f+4}$?

Слово UCPC має дві літери 'C' (роль 2 і роль 4). Якщо одна лампа може грати ОБИДВІ ролі 'C', їхні кольори збігаються ($c_2 = c_4$) $\implies$ маємо 3 незалежні кольори для букв ($3^{f+3}$). Якщо ні — всі 4 літери мають незалежні кольори ($3^{f+4}$)!

Задача D: Парні та непарні (Evens and Odds) — «Баланс парності»

Число збалансоване, якщо сума непарних цифр на парних позиціях дорівнює сумі парних цифр на непарних позиціях. Дописуємо мінімальний блок цифр $k$ справа за $O(|N|)$.

Перебір усіх суфіксів: 10^k ❌ TLE
Жадібний пошук: O(|N|) ✅ 100 балів

Пояснення на пальцях (для чайників)

⚖️ Бухгалтерський баланс:

Непарні цифри на парних місцях — це прибуток ($+d$), а парні на непарних місцях — витрати ($-d$). Баланс повинен точно дорівнювати 0.

🎯 Чому не треба перебирати всі суфікси?

Ми просто перевіряємо довжину суфікса $k = 1, 2, 3 \dots$. Для фіксованого $k$ математична формула діапазону $[low, high]$ за $O(1)$ точно знає, чи можна компенсувати різницю такими цифрами!

✨ Жадібний вибір найменшої цифри:

Оскільки треба мінімальне число, на першу позицію суфікса ми пробуємо ставити $0$, потім $1$, потім $2$... перша цифра, яка залишає задачу розв'язною, і є нашою!

Задача G: Числова гра (Number Game)

За один крок дозволено переставити нулі (зберігаючи popcount) та замінити $x \to x + 1$. Знайти мінімум кроків від $n$ до $m$.

O(|n| + |m|) Біти

Інваріант Popcount

1. Число $c = \text{popcount}(n)$ за один крок переходить у будь-яке число з $[1, c+1]$.

2. Число $m$ досягається лише з $m-1$, у якого $p = \text{popcount}(m-1)$ одиниць.

3. Якщо $c = p \implies 1$ хід; якщо $c > p \implies 2$ ходи; якщо $c < p \implies p - c + 1$ ходів.

Задача K: Сума і добуток (Sum and Product) — «Теорема Вієта»

Мінімальна кількість дійсних чисел $n$ таких, що $\sum a_i = s$ та $\prod a_i = 1$. Чисельно стабільна формула Вієта без втрати точності за $O(1)$.

Діапазон n: Тільки 1, 2 або 3!
Складність: O(1) Час / Пам'ять

Пояснення на пальцях (для чайників)

1. Чому відповідь ніколи не більше 3?

Якщо $s = 1$, беремо число 1 ($n=1$). Якщо $|s| \ge 2$, вистачає 2 чисел ($n=2$). А якщо $|s| < 2$, додаємо число $-1$ і отримуємо 3 числа ($n=3$)!

2. Звідки береться квадратне рівняння?

Для двох чисел $a_1 + a_2 = s$ та $a_1 \cdot a_2 = 1$. За формулами Вієта це корені $t^2 - st + 1 = 0$. Дискримінант $D = s^2 - 4$.

3. Магія числа -1:

Якщо $D < 0$, фіксуємо $a_1 = -1$. Тоді $a_2 a_3 = -1$, а $a_2 + a_3 = s + 1$. Дискримінант стає $(s+1)^2 + 4 > 0$, що ЗАВЖДИ додатно! Корінь гарантовано існує!

Задача N: Щоденник погоди (Weather Diary) — «Ейлерів шлях»

Перевірка можливості існування щоденника погоди з переходами $u$ ($S \to R$), $v$ ($R \to S$), $e$ ($S \to S$) та $g$ ($R \to R$). Відповідь за $O(1)$!

Граф станів: 2 вершини (Sun / Rain)
Складність: O(1) Перевірка

Пояснення на пальцях (для чайників)

☀️🌧️ Маятник між двома кімнатами:

У нас лише два типи днів: Сонячно ($S$) та Дощ ($R$). Кожен вихід $S \to R$ ($u$) вимагає обов'язкового повернення $R \to S$ ($v$), щоб знову опинитися на сонці!

⚖️ Інваріант |u - v| ≤ 1:

Кількість поїздок «туди» і «назад» не може відрізнятися більше ніж на 1! Якщо $|u - v| > 1$, такий щоденник топологічно неможливий $\implies$ виводимо NO.

📅 Самовипадіння e та g:

Дні $S \to S$ ($e$) та $R \to R$ ($g$) просто вклеюються всередину перших сонячних або дощових серій. Відповідь конструюється за $O(1)$!

Анімація розповсюдження хвилі BFS

Натисніть «Пуск» або «Крок», щоб запустити чергу FIFO та побачити рівневі хвилі відстаней.

Пастка #1: Visited Trap

1. Помилка 80% олімпіадників: помічати клітинку відвіданою не при додаванні в чергу (push), а при вилученні (pop).

2. Результат: клітинка потрапляє в чергу багатократно від усіх 4 сусідів! Черга роздувається до мільйонів елементів → Memory Limit Exceeded.

3. Золоте правило: dist[nr][nc] = cur + 1 строго перед q.push({nr, nc})!

// Шаблон олімпіадного BFS
queue<pair<int,int>> q;
dist[sr][sc] = 0;
q.push({sr, sc});

while (!q.empty()) {
    auto [r, c] = q.front(); q.pop();
    if (r == er && c == ec) break;
    for (int i = 0; i < 4; ++i) {
        int nr = r + dr[i], nc = c + dc[i];
        if (valid(nr, nc) && dist[nr][nc] == -1) {
            dist[nr][nc] = dist[r][c] + 1;
            q.push({nr, nc}); // Visited ОДРАЗУ!
        }
    }
}
