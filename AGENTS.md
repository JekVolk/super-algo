# Super-Algo: Правила, Архітектура та Бойовий Регламент

## Спеціалізація та суб-агенти
1. **`algo-coach`** — Ментор та педагог:
   - Розжовує рішення «для чайників», будує інтуїцію, порівнює наївний підхід з оптимальним.
   - Генерує еталонний код на C++20 та Python 3.12.
2. **`algo-mindmapper`** — Систематизатор знань:
   - Декомпозує кожну задачу на 5 рівнів: Макро -> Тема -> Підтема -> Мікро -> Нано.
   - Будує Mermaid Mind Map для кожної теми та дерева рішень.
3. **`algo-contest-tester`** — Майстер верифікації та стрес-тестів:
   - Пише наївні алгоритми, рандомайзери, знаходить мінімальний контрприклад через `scripts/stress_tester.py`.

## ⚡ Обов'язковий 8-Кроковий Стандарт Розбору Задач
Кожна надіслана користувачем задача або "шпора" розбирається СУВОРО за цим алгоритмом:

1. **Вдупляння (Sense-Making):** людською мовою без води, що є об'єктами, що дозволено робити, що насправді просять. Виділення **слів-маркерів** в умові (див. [docs/PROBLEM_KEYWORDS_AND_MARKERS.md](file:///C:/project/super-algo/docs/PROBLEM_KEYWORDS_AND_MARKERS.md)).
2. **Ручні крайові тести:** 3 власні ручні тести ($N=1$, мінімум/максимум, контр-приклад).
3. **Аналіз лімітів і бюджет часу:** $N, TLE, MLE$, точне визначення допустимої складності $O(...)$.
4. **Вибір алгоритму з Mind Map та слів-маркерів:** позиція в [docs/ALGORITHM_DECISION_TREE.md](file:///C:/project/super-algo/docs/ALGORITHM_DECISION_TREE.md) та звірка з логічними тригерами [docs/PROBLEM_KEYWORDS_AND_MARKERS.md](file:///C:/project/super-algo/docs/PROBLEM_KEYWORDS_AND_MARKERS.md).
5. **Доведення та Інваріант:** чому наївний падає, чому оптимальний працює, математичний інваріант.
6. **Двомовний код (C++20 та Python 3.12):** чистий олімпіадний код з коментарями.
7. **Аудит граблів та людських помилок:** каталог типових помилок, через які 80% людей отримують WA/TLE/MLE (забутий `1LL`, нескінченний бінарний пошук, переповнення стеку).
8. **Стрес-тест та командна стратегія:** наївний код, скрипт генератора для `scripts/stress_tester.py`, ICPC рекомендації для 3 учасників.

## 🛡️ Суворі Обмеження та Захист від Галюцинацій/Мутацій
Щоб гарантувати 100% якість та унеможливити деградацію рішень:

1. **Атомарний Пайплайн (Strict Isolation):**
   - **Заборонено пакетну (bulk) генерацію або масовий рефакторинг.** Кожна задача опрацьовується строго ізольовано (1 сесія = 1 задача).
   - Заборонено залишати плейсхолдери (`TODO`, `див. далі`, скорочення коду).
2. **Абсолютна Математична Чистота (LaTeX/KaTeX Standard):**
   - **Заборонено вставляти сирі артефакти OCR:** рядки на кшталт `b =v max{d −j dist(c ,v)},j` чи `v=c` вважаються грубим браком.
   - Усі формули записуються суворо у чистому LaTeX: `$b_v = \max(d_j, b_{a_v} - 1)$`, `$3^{f+3}$`, `$O(N \log N)$`.
   - В усіх веб-інтерфейсах обов'язково активний KaTeX з `renderMathInElement` для унеможливлення «сповзання» формул.
3. **Контроль Коректності Коду та Тестів (Verification Gate):**
   - Перед створенням пояснення код на C++20 та Python 3.12 обов'язково проганяється через `test_runner.py` або `stress_tester.py`.
   - Заборонено підганяти відповіді в тестах (як було з $3^f+3$ замість $3^{f+3}$).
4. **Повнота Покриття (100% Coverage):**
   - У контесті мають бути розібрані **ВСІ** задачі без винятку:
     * **UCPC 2026 I Етап:** усі 14 задач (A, B, C, D, E, F, G, H, I, J, K, L, M, N)
     * **UCPC 2026 Пробний тур (Eolymp):** усі 10 задач (A–J: стандартні 1–6, інтерактивна G, multi-run H, output-only I, function-without-main J)
   - Кожна задача повинна мати свій `README.md` (8 кроків), `solution.cpp`, `solution.py`, `test_runner.py`, `stress_tester.py` та за потреби покрокову візуалізацію в `web/ucpc_animator.html`.
5. **Перевірка перед комітом (Pre-Commit Zero Tolerance):**
   - Перед фіксацією змін обов'язково проганяти повні сьюти:
     * `python tasks/test_all_stage1.py` (14/14 OK)
     * `python tasks/test_all_practice.py` (10/10 OK)

## 🛠️ Інструменти екосистеми
- **Головне консольне меню:** `python scripts/menu.py` (або `super-algo.bat`)
- **Слухач турів:** `python scripts/companion_listener.py` (порт 10043 для Competitive Companion)
- **Скрапер Eolymp:** `python scripts/eolymp_scraper.py` (збереження контестів, умов, тестів)
- **Імпортер Codeforces:** `python scripts/cf_fetcher.py <contestId> <index>`
- **Стрес-тестувальник:** `python scripts/stress_tester.py gen.py fast.py naive.py 500` (підтримка C++20 та Python 3.12)
- **Бібліотека генерації стрес-тестів:** `scripts/test_gen_lib.py` (бамбуки, зірки, зважені графи)
- **Лінтер олімпіадних граблів:** `python scripts/pitfall_detector.py tasks/`
- **Калькулятор складності та TLE:** `python scripts/tle_predictor.py --n 200000 --complexity NlogN --tl 1.0`
- **Інтерактивне Дерево та 5-рівневий навігатор:** `python scripts/open_visualizer.py` (файл `web/index.html`)
- **Покроковий Аніматор Задач UCPC:** `python scripts/open_visualizer.py anim` (файл `web/ucpc_animator.html`)
- **REST API бекенд:** `uvicorn api.main:app --reload --port 8000` (Swagger UI: `/docs`)
